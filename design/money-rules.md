# 시작 돈 100만원 + 용돈 봉투 확률 — 설계서

## 1. 한 줄 요약
시작 돈을 **1,000만원 → 100만원**으로 줄여, 카드 한 장·주식 한 번 사는 것도 고민하게 만든다. 용돈 봉투는 **정해진 50만원 대신 공개된 확률로 받거나 잃는** 카드가 된다.

## 2. 규칙

### 돈 단위 (모두 1/10)
| 항목 | 지금 | 바뀐 뒤 |
|---|---|---|
| 시작 돈 | 1,000만원 | **100만원** |
| 카드 값 | 10만~60만원 | **1만~6만원** (내일 신문 6만, 애널리스트 3만, 차트 분석·거래 정지·수수료 폭탄·방패 2만, 염탐·정보 차단 1.5만, 감별기·가짜 뉴스 1만, 반사 거울 4만) — 1대1 방해 카드 1.5배는 그대로 |
| 상대 재산 숨김 단위 | 10만원 | **1만원** |
| 업적 기준 금액 | 예: 배당 10만원 | 1/10 로 |

주식 가격은 **그대로**: 비싼 주식은 1~2주밖에 못 사는 게 오히려 "고르는 재미" (미국 퀀틱스 약 56만원 = 1주). 수익률·레버리지 30% 제한·랭킹 점수는 비율이라 영향 없음.

### 용돈 봉투 (무료 카드로만 나옴, 확률은 카드에 그대로 공개)
| 결과 | 확률 |
|---|---|
| +30만원 | 5% |
| +15만원 | 15% |
| +8만원 | 30% |
| +3만원 | 25% |
| **−5만원** | 15% |
| **−10만원** | 10% |

- 평균 기대값 약 **+5.2만원** (시작 돈의 약 5% — 지금 50만/1,000만과 같은 비율)
- 잃는 돈은 현금에서 빠지고, 현금이 모자라면 0원까지만 (빚 없음)
- 결과는 **서버가 뽑음**(방 비밀값으로 만든 전용 난수, 가격과 무관) → 화면이 결과를 미리 알 수 없음

## 3. 서버가 정하는 것 / 화면에 보내는 것
| 화면에 보냄 | 절대 안 보냄 |
|---|---|
| 내 봉투 결과(쓴 뒤), 공개 확률표 | 다음 봉투 결과·난수 |
| 상대 재산(1만원 단위 구간) | 상대 봉투 결과·정확한 재산 |

## 4. DB 변경
없음 (봉투 결과는 기존 카드 사용 기록 `payload` 에 서버가 저장). 규칙 버전은 `room_secrets.rules_version = 6` (장 전 시간과 같이 묶음).

## 5. 진행 중인 게임
v6 방부터만. v5 이하 방은 1,000만원·고정 50만원 그대로. 튜토리얼도 v6 금액으로 문구 수정.

## 6. 화면
- 금액 표시: 100만원이면 초보 모드 '만원' 표시가 자연스러움 (예: 103만 2,500원)
- 금액 버튼(+10만·+50만·+100만) → **+1만·+5만·+10만·살 수 있는 만큼**
- 봉투 카드 뒷면/설명에 확률표, 쓰면 결과 연출(돈이 들어오거나 빠지는 짧은 애니메이션)

## 7. 악용
| 시도 | 막는 법 |
|---|---|
| 결과가 나쁘면 새로고침해서 다시 | 결과는 쓰는 순간 서버에서 확정·저장 |
| 화면에서 확률 바꾸기 | 확률·금액은 서버 코드에만 (화면 표는 보여 주기용) |
| 동시에 두 번 쓰기 | 기존 카드 사용과 같은 한 번만 규칙(장수 차감 후 처리) |

## 8. 완료 기준
- [ ] v6 방은 100만원으로 시작, v5 방은 1,000만원 그대로 (단위 테스트)
- [ ] 봉투 결과 분포가 확률표와 맞다 (10만 번 시뮬, ±1%)
- [ ] 봉투로 현금이 0 아래로 내려가지 않는다 (단위 테스트)
- [ ] 화면 데이터에 다음 봉투 결과가 없다 (단위 테스트)
- [ ] 1대1·4인 시뮬 승률 쏠림이 기존과 비슷 (sim)
- [ ] 금액 버튼·카드 값·업적 문구가 모두 새 단위 (브라우저 3가지 크기)
