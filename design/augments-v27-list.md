# 개미리그 증강 목록 2판 — 우리 게임 숫자에 맞춤

## 기준 (봇 300판 시뮬 + 실제 판 DB, 시작 돈 100만원·10일)
- 목표 가치: **실버 ≈ 1.2만원 · 골드 ≈ 3만원 · 프리즘 ≈ 6만원** (재산의 약 1.2% · 3% · 6%)
  - 실력이 섞인 판에서 1위 확률을 실버 +1~3%p · 골드 +3~8%p · 프리즘 +10~15%p 올리는 정도 — 뉴스 잘 읽는 쪽 이득(+7~10%)보다 작게.
- 그래서 바뀐 것
  - **수수료 증강은 혼자서는 뺌**: 실제 사람은 한 판 수수료가 평균 2천원(0.2%), 상위 10%도 7.7천원. 면제해도 실버에 못 미침 → 다른 효과에 덤으로만.
  - **예약 주문 개수·범위 늘리기도 덤으로만**: 거의 안 써서 값이 0에 가까움.
  - **레버리지 한도 60%**: 시뮬에서 승률이 오히려 조금 내려감(아침 뉴스가 이미 시가에 반영) → '놀이 방식' 실버로만.
  - **배당**: 한 판에 기준일 1번, 평균 배당률 2.7% → '2배'도 판당 0~0.8% → 실버 + 기준일 미리 알림.
  - **모든 돈 보너스에 판당 상한**(접전에선 1%로도 판이 갈려서). 서버가 장 마감 때 계산, 상한·누적액을 DB 에 저장.
  - 정보 증강 값은 예전 카드 시뮬 값으로 맞춤: 내일 헤드라인 1번 ≈ 3만원, 강한 업종 1번 ≈ 3만원, 오를지 내릴지 1번 ≈ 1만원, 소식 진위 1번 ≈ 1만원.

표시: ⏳ 시간이 지나야 효과(남은 날이 모자라면 안 뜸) · 🎯 조건이 맞아야 뜸 · 👥 여럿이 하는 판에서만 · 🎲 운 · ⚖️ 대가 · **초/중/후** = 뜰 수 있는 고르기 차례

## 넣지 않은 것
- 상대 보유·거래 보기, 1위가 무엇을 가졌는지 간접으로 드러나는 것 — 상대 정보 숨김
- 진위를 원래보다 일찍, 속보가 곧 뜬다고 알려 주는 것 — 미래·진실 정보 규칙
- 상대를 방해하는 것 — 카드를 없앤 취지
- 카운트다운·장 전 시간 바꾸기 — 방 전체 공통
- 수수료·예약만 바꾸는 증강 — 값이 너무 작음(덤으로만)
