# 개미리그 증강 목록 (초안 — 숫자는 시뮬로 맞춤)

증강 = 판 끝까지 이어지는 나만의 효과. 모두 서버가 계산하고, 상대에게는 판이 끝날 때까지 보이지 않음.
등급: **실버**(작은 이득) · **골드**(뚜렷한 이득) · **프리즘**(판을 바꾸는 이득, 대가가 있기도 함).
표시: ⏳ = 시간이 지나야 효과(늦게 고르면 안 뜸) · 🎯 = 조건이 맞아야 뜸 · 👥 = 여럿이 하는 판에서만 · 🎲 = 운이 섞임 · ⚖️ = 대가가 있음

같은 이름 I·II·III 은 롤토체스처럼 **같은 효과의 등급별 판**(한 사람은 같은 집안 중 하나만).

## 넣지 않은 것 (이유)
- 진위를 원래보다 일찍 알려 주는 것, 속보가 곧 뜬다고 알려 주는 것 — 미래·진실 정보 규칙
- 1위가 무엇을 가졌는지 간접으로 드러나는 것 — 상대 정보 숨김
- 상대 보유·거래 보기 — 상대 정보 숨김 원칙
- 상대를 방해하는 증강 — 카드 없애는 취지(재미보다 스트레스), 1인 표적 문제
- 카운트다운·장 전 시간 바꾸기 — 방 전체 공통
- 가격을 미리 보는 것(내일 가격, 장중 미래 칸) — 보안 규칙
- 공매도 — 새 규칙이 너무 큼
