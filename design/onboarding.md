# 처음 온 사람 안내 + 단계별 튜토리얼 + 게스트 이어하기 코드 (설계서)

## 한 줄 요약
처음 들어오면 "게스트로 / 로그인 / 회원가입"을 고르고, 바로 이어서 롤 클라이언트처럼 **홈 → 게임 → 결과 → 미션·업적** 순서로 안내를 받는다. 언제든 건너뛸 수 있고, 단계별로 따로 다시 볼 수 있다. 게스트는 **이어하기 코드**로 다른 기기·브라우저에서 같은 게스트 기록을 이어 갈 수 있다.

## 1. 처음 들어왔을 때 (환영 창)
- 뜨는 때: 이 기기에서 처음(로그인 세션 없음 + 환영 창을 본 적 없음). 주소가 초대 링크(`/room/코드`)·게임 주소면 그 흐름을 먼저(환영 창은 그 뒤 로비에서).
- 환영 창 1단계 — 3개 버튼: **게스트로 시작** / **로그인** / **회원가입** (+ 오른쪽 위 닫기 = 게스트로 둘러보기, 지금처럼 온라인 기능을 누를 때 다시 물음)
- 게스트로 시작 → 닉네임 칸(지금 게스트 창과 같은 확인: 1~10자, 회원 닉네임과 겹치면 안내) + **"시작하기"**
  - 아래 작은 글: **"이미 게스트로 해 본 적 있나요? 이어하기 코드로 불러오기"** → 코드 입력 칸으로 바뀜
- 회원가입 화면 아래: **"이미 회원이세요? 로그인"** (지금 탭 3개 위에 더해 글 링크로도)
- 로그인 화면 아래: **"아직 회원이 아니에요? 회원가입"**

## 2. 튜토리얼 — 4개 단계로 분리
| 단계 | 어디서 | 내용 (말풍선 + 밝게 비추기, 지금 게임 튜토리얼과 같은 모양) |
|---|---|---|
| ① 홈 둘러보기 (약 1분) | 로비 | 플레이 버튼·모드(일반전/랭킹전/커스텀/연습)·1대1·다인전·신속/일반 → 봇전·오늘의 도전 → 미션 버튼 → 프로필 → 친구(PC 오른쪽 칸 / 휴대폰 아래 탭) → 설정·더보기 |
| ② 게임 기초 (약 3분) | 연습봇과 한 판 | 지금의 15단계 그대로 (뉴스·차트·사기·카드·감별기·장 마감·결산·순위) — 끝나면 결과 화면으로 |
| ③ 결과 보기 (약 30초) | ②의 결과 화면 | 순위·수익률·이번 판 업적·하루별 리플레이·자산 추이·시장 성적·한 판 더 |
| ④ 성장 (약 40초) | 로비 | 미션(오늘·이번 주, 바꾸기)·경험치·레벨·업적 화면·칭호·프로필 사진·티어(회원) |

- 흐름: 환영 창 → "튜토리얼 할까요? (약 5분, 언제든 건너뛰기)" **[시작] [건너뛰기]** → ①→②→③→④ 이어서. 단계마다 오른쪽 위 **건너뛰기**(그 단계만) / **튜토리얼 그만하기**(전부).
- 다시 하기: 연습 메뉴 '튜토리얼' 칸과 설정·더보기 '튜토리얼' 줄 → **단계 목록**(①~④ 각각 시작 버튼 + 끝낸 단계는 ✓).

## 3. 튜토리얼이 자동으로 뜨는 때 (잘 생각한 기준)
- 자동 제안은 **처음 하는 사람에게만**: 환영 창에서 게스트·회원가입을 고른 직후 / 로그인한 회원이라도 **끝낸 판이 0판이고 튜토리얼 기록이 없으면** 로그인 직후 한 번.
- 안 뜨는 때: 이미 판을 한 적이 있는 계정, 한 번이라도 '건너뛰기'·'그만하기'를 고른 계정(그 계정 기록), 초대 링크로 바로 방에 들어가는 중, 매칭 대기 중·게임 중.
- 기록 위치: 회원·게스트 모두 **서버 계정 기록**(profiles 가 없는 게스트는 새 표) — 다른 기기에서 로그인해도 다시 안 뜸. 서버에 못 물을 때(인터넷 설정 없음)는 이 기기 기록만.
- 이미 있는 '처음이세요? 튜토리얼' 카드는 ② 단계 바로가기로 남김(튜토리얼 기록이 있으면 숨김 — 지금 규칙).

## 4. 게스트 이어하기 코드
- 받는 곳: 설정·더보기 '내 계정'(게스트일 때) **"이어하기 코드 받기"** → 코드 한 번만 보여 줌(복사 버튼). 다시 받으면 예전 코드는 못 씀. 첫 판을 끝낸 게스트 결과 화면에도 작은 안내 한 줄.
- 코드: 무작위 12자리(헷갈리는 글자 뺀 32글자, 60비트) `XXXX-XXXX-XXXX`, 서버는 **해시(scrypt)만** 저장(복구 코드와 같은 방식).
- 쓰기: 환영 창 '이어하기 코드로 불러오기' → 서버가 코드를 확인 → 그 게스트 계정으로 로그인(서버가 새 임시 비밀번호를 정해 로그인 정보만 돌려줌 — 지금 손님 계정 만들 때와 같은 방식). 성공하면 코드는 **한 번 쓰고 끝**(새 기기에서 새로 받기). 다른 기기의 예전 세션은 끊음(revoke).
- 지금 이 기기의 게스트 기록이 있으면: "지금 기기의 게스트 기록은 사라져요" 확인(회원 로그인 때의 '게스트 기록 가져오기/버리기'와 같은 선택을 재사용).
- 회원은 대상 아님(같은 아이디로 로그인). 2026-11-17 에 없앤 '대결 이어하기 코드'(게임 자리 옮기기)와는 다른 것 — 계정 단위.

## 5. 서버가 정하는 것 / 화면에 보내는 것
| 서버만 | 화면에 보냄 |
|---|---|
| 코드 해시, 코드로 찾은 계정 id, 임시 비밀번호 생성 | 코드는 만들 때 한 번만, 불러오기 결과는 로그인 정보(가짜 이메일·임시 비밀번호)만 |
| 튜토리얼 기록(단계별 끝냄/건너뜀 시각) | 내 단계별 상태(참/거짓)만 |
| 시도 횟수(IP·전체) | 실패는 늘 같은 문구("코드가 맞지 않아요") |

## 6. DB 변경 (`051_onboarding.sql`, 여러 번 실행해도 안전)
- `guest_codes(user_id uuid pk → auth.users on delete cascade, code_hash text, created_at)` — 서버만(RLS·권한 회수)
- `tutorial_progress(user_id uuid pk, done text[] , skipped bool, updated_at)` — 서버만
- `guest_code_attempts` (IP 해시·시각) 또는 기존 `pw_attempt_fail` 방식 재사용: IP 당 10분 5번, 전체 1분 30번
- 적용 전이면 서버는 코드 기능 503 안내·튜토리얼은 이 기기 기록만 (죽지 않게)

## 7. 진행 중인 게임 영향
없음(시장·규칙 버전 그대로). 튜토리얼 ②는 지금처럼 브라우저 연습 판(v3 고정 장면).

## 8. 화면
- 환영 창: 휴대폰 = 아래에서 올라오는 전체 높이 창 / PC = 가운데 창(480px). 로고 + 한 줄 소개 + 3버튼.
- 튜토리얼 ①④: 지금 게임 튜토리얼 말풍선·밝게 비추기(`TutorialGuide` 모양)를 로비용으로. PC·휴대폰 각각 가리킬 대상이 다름(PC 위 메뉴·오른쪽 친구 칸 / 휴대폰 위 머리줄·아래 탭).
- 겹친 창 규칙(useEscape 순서) 지킴: Esc = 그 단계 건너뛰기 확인, 뒤로 가기 = 말풍선 한 단계 앞.

## 9. 악용 시나리오와 막기
- 코드 맞히기: 60비트 + 시도 제한(IP·전체) + 늘 같은 실패 문구·같은 시간.
- 코드 훔쳐보기: 한 번 쓰면 끝, 새로 받으면 예전 것 무효, 해시만 저장, 로그·오류 기록에 코드 안 남김.
- 회원 계정을 코드로 열기: 서버가 대상이 게스트(아이디 없음)인지 확인, 회원이면 거절.
- 남의 게스트 기록 덮어쓰기: 불러오기는 "로그인"일 뿐, 지금 기기 기록은 사용자 확인 후에만 버림.
- 튜토리얼 기록 조작: 기록은 표시용(보상 없음). 튜토리얼에 경험치·업적을 걸지 않음.

## 10. 완료 기준
- [ ] 처음 들어오면(세션·기록 없음) 환영 창이 뜨고, 초대 링크로 들어오면 방 흐름이 먼저 (브라우저)
- [ ] 게스트 → 닉네임 확인 → 시작, 회원가입 아래 '이미 회원이세요? 로그인', 로그인 아래 '회원가입' (브라우저)
- [ ] 튜토리얼 ①~④ 이어서 진행, 단계마다 건너뛰기·전체 그만하기 (휴대폰·PC)
- [ ] 연습·설정에서 단계 목록으로 각 단계를 따로 다시 시작 (브라우저)
- [ ] 판을 한 적 있는 계정·건너뛴 계정은 자동으로 안 뜸, 다른 기기에서 로그인해도 안 뜸 (e2e)
- [ ] 게스트 코드: 만들 때 한 번만 보임, 서버엔 해시만, 쓰면 끝, 새로 받으면 예전 것 무효, 회원 계정엔 안 됨, 시도 제한, 실패 문구 같음 (e2e `guestcode.mjs`)
- [ ] 코드로 불러오면 그 게스트의 전적·업적·미션이 그대로 (e2e)
- [ ] 화면 데이터·응답에 코드 해시·다른 계정 id 없음 (단위 + e2e)

## 추가 결정 (2026-11-18, 사용자)
1. **둘러보기 전용**: 게스트로 시작·로그인·회원가입 중 하나를 고르기 전(세션 없음)에는 화면을 둘러보기만 한다. 대결 찾기·방·연습·봇전·튜토리얼·화면 편집 등 '하는' 버튼은 모두 환영 창을 띄운다. 설정의 게스트 닉네임 칸도 안 보이고 대신 '시작하기'.
2. **로그아웃**: 회원은 PC 프로필 팝업·설정 '내 계정'·마이프로필에서 로그아웃. 게스트도 '게스트 그만하기(로그아웃)' — "이어하기 코드가 없으면 이 게스트로 돌아올 수 없어요" 확인.
3. **다른 게스트로 이어하기**: 게스트일 때 설정 '내 계정'에 '다른 게스트 코드로 이어하기'. 지금 게스트에서 빠지기 전에 같은 확인.
4. **게스트 정보 보관**: 회원처럼 서버에 계속 보관(전적·업적·미션·경험치). 지우는 건 '데이터 지우기'를 직접 눌렀을 때뿐. (나중에 오래 안 쓴 게스트를 지울지는 따로 정함)
5. **동시 접속 막기 — 나중에 들어온 곳이 이김**: 한 계정은 한 곳에서만. 다른 브라우저·기기에서 로그인(또는 게스트 코드로 불러오기)하면 예전 곳은 다음 요청 때 "다른 곳에서 접속해서 이 기기는 로그아웃됐어요" 안내 후 둘러보기 상태로. 같은 브라우저의 여러 탭은 같은 접속(지금처럼 게임은 한 탭에서만 띠로 안내).
   - DB `active_sessions(user_id, session_id, created_at)` + 서버 전용 함수 `session_check(사용자, 세션)`: 요청의 세션이 기록보다 새 것이면 바꾸고 예전 세션은 끊음(auth.sessions 삭제), 예전 것이면 거절. 서버는 요청마다 확인(같은 세션은 10초 동안 기억).
   - 거절은 401 + `code: 'replaced'` → 화면은 새 손님을 만들지 않고 안내 후 둘러보기로.
6. **게스트 코드는 계속 쓰는 코드 + 언제든 다시 보기**: 새로 받기 전까지 같은 코드. 게스트는 설정 '내 계정'에서 **언제든 코드 보기**(복사). 서버는 코드를 **암호화(AES-256-GCM, 서버 비밀 키에서 만든 키)** 해 보관하고 찾기용은 HMAC. '새 코드로 바꾸기'를 누르면 예전 코드는 못 씀.
   - 고지: "이 코드를 가진 사람은 누구나 이 게스트로 들어올 수 있어요. 코드 관리는 본인 책임이에요. 남에게 보여 주지 마세요." (코드 보기·받기·불러오기 화면 모두)
   - 불러오면 위 5번에 따라 예전 기기는 로그아웃.
