# 정식 출시 계획 (2026-11-20)

## 1. 출시 플랫폼 결정: **웹 + 설치형 웹앱(PWA)으로 먼저 정식 출시 → 다음 단계 구글 플레이(TWA)**

| 후보 | 비용 | 우리 게임과 맞는 정도 | 판단 |
|---|---|---|---|
| **웹 / PWA** | 0원 (지금 Vercel 무료) | 휴대폰·PC 모두, 링크 하나로 친구 초대(1대1·파티·초대 링크가 핵심 재미), 업데이트 즉시 반영, 이미 '앱처럼 쓰기' 안내까지 있음 | **지금 정식 출시** |
| 구글 플레이 | 개발자 등록 25달러(한 번) | 한국 이용자 대부분 안드로이드, 같은 웹 코드를 TWA로 감싸 그대로 올림 — 스토어 노출·검색 | **다음 단계** (등록비 = 외부 요인, 준비물은 지금 만들어 둠) |
| 앱스토어 | 99달러/년 + 맥 필요 | 웹을 감싼 앱은 심사에서 자주 거절(4.2 최소 기능) | 나중 (이용자가 모인 뒤) |
| 스팀 | 앱마다 100달러 | PC 게이머 중심·영어권 위주, 짧은 턴제 모바일 친화 게임과 결이 다름, 데스크톱 포장(Electron) 필요 | 추천 안 함 (지금은) |

이유 요약: ① 비용 0 ② 대결 게임이라 '링크로 바로 같이 하기'가 가장 큰 무기 ③ 휴대폰 이용자가 대부분인 한국 캐주얼 주식 게임 ④ 서버가 늘 필요해서 스토어 앱도 결국 같은 웹을 씀.

## 2. 비용 없이 할 일 (진행 기록)
- [ ] PWA: 매니페스트 스크린샷(설치 창이 스토어처럼)
- [ ] 구글 플레이 준비물: TWA 설정 문서(assetlinks 자리, 스토어 문구·스크린샷·등급 설문 답 초안)
- [x] 버그 조사: 튜토리얼 끝 → 홈 뒤 시험용 헤드리스 크롬이 10초쯤 뒤 멈춤 — 메모리·화면 계산 횟수·이벤트 수 모두 그대로(우리 코드의 반복·누수 없음), 소리 끈 채·GPU 끈 채도 같음, 같은 저장값으로 새로 열면 안 생김 → 시험 환경 문제로 보고 지켜봄 (운영 오류 기록 server_errors·ErrorBoundary 로 확인)
- [x] PWA: 서비스 워커(인터넷 끊김 안내 화면만, 게임 코드·데이터 저장 안 함), 매니페스트 바로가기·분류
- [ ] 처음 10분 경험(첫 화면 → 첫 판 → 결과 → 다음 판) 다듬기
- [ ] 수익 구조 설계(결제·광고는 사업자·계약이 필요한 외부 요인 → 설계와 화면 자리만): 꾸미기만 파는 공정한 구조, 실력에 영향 없음
- [ ] 사운드: 배경 음악(BGM)·효과음 다듬기 — 직접 합성(Web Audio)이라 저작권·비용 없음, 장면별 음악(로비·장중·속보·결과), 음량 따로 조절·끄기, 접근성(움직임 줄이기와 별개로 소리 끄기 기억)
- [ ] 문구 전체 점검(쉬운 말·일관된 용어)
- [ ] 밸런스·게임 진행: 시뮬레이터로 확인
- [ ] 접근성·성능·보안 마지막 점검, 배포

## 3. 사용자가 직접 해야 하는 것 (외부 요인)
- 구글 플레이 개발자 등록(25달러), 앱 서명 키 만들기 → assetlinks.json 지문 넣기
- 결제(인앱·후원)를 열려면 사업자 등록·결제 대행 계약
- 국내 게임 배포: 게임물관리위원회 등급분류(구글 플레이는 IARC 설문으로 대신, 무료)
