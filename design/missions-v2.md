# 미션 2판 — 일일 6개 · 주간 3개 · 하루 3번 바꾸기

## 한 줄 요약
**일일 미션 6개**(하루 안에 깰 수 있는 것)와 **주간 미션 3개**(일주일에 걸쳐 깨는 것)가 사람마다 다르게 나와요. 마음에 안 드는 **미완료 일일 미션은 하루 3번까지 다른 미션으로 바꿀** 수 있어요.

## 규칙
| | 일일 미션 | 주간 미션 |
|---|---|---|
| 개수 | 6개 (쉬움 3 · 보통 3) | 3개 (보통 1 · 어려움 2) |
| 갱신 | 매일 0시 (한국) | 월요일 0시 |
| 고르는 곳 | **일일 전용 목록**에서만 | **주간 전용 목록**에서만 (둘이 겹치지 않음) |
| 바꾸기 | 미완료 미션만, 하루 3번 (주간 미션 포함 합계 3번) | 같은 3번 안에서 |
| 사람마다 다름 | 지금처럼 서버 비밀 키 HMAC(계정+기간+바꾼 횟수) | 같음 |
| 보상 | 쉬움 20~30 · 보통 40~50 | 보통 120 · 어려움 150~200 |

- 하루 미션 경험치 상한 300 → **450**(6개 다 깨면 약 210~240 + 여유). 판 경험치 상한 600은 그대로. 주간 미션은 상한에 넣지 않음.
- 바꾼 미션 칸은 같은 목록에서 **지금 없는 것** 중 하나로. 진행 중이던 칸(1/3 등)은 바꾸면 진행이 사라짐을 확인창으로 알림.

### 일일 미션 목록 (하루 안에)
쉬움: 대결 1판 끝까지 · 루머 감별기 1번 · 예약 주문 1번 체결 · 장중 속보 종목 사기 · 오늘의 도전 하기 · 한 판에서 거래 5번 넘게 · 봇전 1판 끝까지 · 찌라시에 나온 업종 종목 사기 · 장 전 시간에 예약 주문 걸기 · 국내·미국 종목 둘 다 한 판에 사기
보통: 수익률 +3% 넘게 마감 · 보통 이상 봇 이기기 · 4명 이상 판에서 3위 안 · 한 판에서 카드 2장 · 대결 1판 이기기 · 종합지수보다 높은 수익률 · 레버리지·인버스 ETF로 수익 내기 · 배당 받기

### 주간 미션 목록 (일주일에 걸쳐)
보통: 대결 5판 끝까지 · 봇전 3판 이기기 · 오늘의 도전 3번
어려움: 대결 3판 이기기 · 고수봇 있는 판 1위 · 수익률 +10% 넘게 마감 · 랭킹전 2판 이기기 · 다인전 1위 · 7일 중 4일 미션 3개 이상 깨기

## 서버가 정하는 것 / 화면에 보내는 것
| 서버만 | 화면에 |
|---|---|
| 고르는 비밀값, 판정(끝난 판 데이터로만), 바꾼 횟수 | 내 미션 목록·진행·보상, 남은 바꾸기 횟수 |
- 화면이 '완료'를 보내는 요청은 지금처럼 없음. 바꾸기 요청 `missionReroll { slot }` 만 새로 — 서버가 미완료인지·남은 횟수인지 확인.

## DB 변경 (`041_missions_v2.sql`, 여러 번 실행해도 안전)
- `mission_rerolls(user_id, period text, count int, slots jsonb, primary key(user_id, period))` — 그날 바꾼 횟수와 칸별로 바뀐 미션 id. 서버만.
- 마이그레이션 전에도 서버가 죽지 않게: 표가 없으면 바꾸기 버튼만 숨김.

## 진행 중인 것에 미치는 영향
- 오늘 이미 받은 미션 3개·진행은 그대로 두고 **내일 0시부터** 6개(지금 3개 + 새 3개처럼 보이지 않게 기간 키에 'v2'를 붙임). 주간도 다음 월요일부터 3개.

## 화면
- 메뉴바 미션 버튼: '미션 2/6'. 팝업: 일일 6개(2열 아님, 한 줄씩) + 주간 3개, 미완료 줄 오른쪽에 **바꾸기(↻)** 버튼, 위에 '바꾸기 2번 남음'.
- 휴대폰: 팝업 높이가 길어지면 안쪽 스크롤.

## 악용 시나리오
- 바꾸기를 연타·동시 요청 → DB 한 줄을 조건부 갱신(count < 3)으로 한 번만.
- 쉬운 미션이 나올 때까지 바꾸기 → 3번 제한, 같은 등급 안에서만 바뀜.
- 다른 사람 미션 보기 → 내 계정 것만.
