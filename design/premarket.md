# 장 전 시간 (프리마켓) — 설계서

## 1. 한 줄 요약
장이 끝나면 바로 다음 날 장이 열리지 않고, **짧은 '장 전 시간'**이 생긴다. 이 시간에 어제를 정리하고, **장 전 찌라시**(진짜인지 모르는 소문)를 보고, 예약 주문을 걸어 둔 뒤 장 시작을 맞는다.

## 2. 규칙
| 항목 | 기본값 (바꾸려면 말씀해 주세요) |
|---|---|
| 장 전 시간 길이 | 신속(하루 60초) **20초** · 일반(하루 90초) **30초** · 커스텀 방은 하루 시간의 ⅓ (최소 15초, 최대 45초) |
| 일찍 끝내기 | 모두 '준비 완료'를 누르면 바로 장이 열림 (1대1·다인전 같음, 기권·자리 비움은 빼고 셈) |
| 할 수 있는 것 | 어제 결산 보기, 찌라시 보기, **예약 주문**(장이 열리는 순간 시가 기준으로 체결 판정), 정보 카드 사용 |
| 못 하는 것 | 지금 가격으로 사고팔기(장이 안 열림), 방해 카드 사용(장 중에만) |
| 장 전 찌라시 | 3~5개. **약 40%는 진짜 단서**(그날 장중 속보·뉴스의 업종/방향을 흐릿하게), **약 60%는 아무 영향 없는 헛소문** |
| 진짜/가짜 표시 | 없음. 루머 감별기를 쓰면 찌라시도 판정해 줌 |
| 첫날 | 1일차는 장 전 없이 바로 (시작 화면 'VS' 뒤 곧장 장) |
| 마지막 날 뒤 | 장 전 없이 바로 최종 결과 |

결산 팝업은 6초 뒤 저절로 닫히고, 장 전 시간에는 '장 마감' 버튼이 '준비 완료'로 바뀌며 찌라시는 뉴스 맨 위에 뜬다. (구현 완료)

## 3. 서버가 정하는 것 / 화면에 보내는 것
| 화면에 보냄 | 절대 안 보냄 |
|---|---|
| 지금이 장 전인지, 장 전 남은 시간 | 찌라시가 진짜인지 (감별기 쓴 사람에게만 판정) |
| 찌라시 문구 | 찌라시가 가리키는 진짜 뉴스·종목 (문구 외 연결 정보) |
| 준비 완료 인원 수 | 오늘 시가 (장이 열리기 전까지) · 상대 예약 주문 |

- 찌라시는 **가격과 다른 전용 난수**(방 비밀값 salt + `:pre`)로 만든다 → 가격은 그대로.
- 진짜 단서는 그날 이미 정해진 뉴스에서 고르므로 새 가격 영향 없음.

## 4. DB 변경
`supabase/025_premarket.sql`: `rooms.open_at`(장이 열리는 시각, null = 장 전 없음) · `players.pre_ready`(준비 완료한 날). 여러 번 실행해도 안전, 컬럼이 없으면 서버는 예전처럼(장 전 없이) 동작.

## 5. 진행 중인 게임
새 규칙 버전 **v6** 방에만 적용. 지금 진행 중인 방(v5 이하)은 예전 그대로. 튜토리얼은 그대로(v3).

## 6. 화면
- **모바일**: 장 전에는 아래 탭 대신 장 전 화면 한 장 — 위: 어제 결산 요약 / 가운데: 찌라시 목록 / 아래 고정: '예약 주문' · '준비 완료(n초)'
- **PC**: 가운데 차트 칸 자리에 장 전 판(결산 + 찌라시), 왼쪽 종목 목록·오른쪽 카드는 그대로(예약 주문용), 위 '장 마감' 버튼 자리가 '준비 완료'
- 스크롤바가 새로 생기지 않게 찌라시는 한 칸에 최대 5개

## 7. 악용 시나리오
| 시도 | 막는 법 |
|---|---|
| 장 전에 지금 가격으로 사기 | 서버가 장 전이면 거래 거절 |
| 준비 완료 눌렀다 취소 반복 | 취소 불가(한 번 누르면 끝), 요청 제한 |
| 화면 데이터로 찌라시 진위 알아내기 | 진위·연결 종목은 서버에만, 문구 길이·순서도 섞음 |
| 일부러 준비 안 누르고 버티기 | 시간 끝나면 자동으로 장 열림 |

## 8. 완료 기준
- [ ] 장 마감 뒤 다음 날 장이 열리기 전 장 전 시간이 있다 (e2e)
- [ ] 장 전에는 지금 가격 주문이 거절되고 예약 주문은 된다 (e2e)
- [ ] 모두 준비 완료하면 남은 시간과 상관없이 장이 열린다 (e2e)
- [ ] 화면 데이터에 찌라시 진위·오늘 시가가 없다 (단위 테스트)
- [ ] 같은 시드의 가격이 v5 와 똑같다 (단위 테스트)
- [ ] 감별기를 쓰면 찌라시도 판정된다 (단위 테스트)
- [ ] 1대1·4인 시뮬에서 승률 쏠림이 기존과 비슷하다 (sim)
- [ ] 모바일 세로·가로, PC 1366×768·1920 에서 막히는 곳·스크롤바 없음 (브라우저)
