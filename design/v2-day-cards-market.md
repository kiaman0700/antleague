## A. 하루 흐름 (장 전 → 정규장 → 빨리 감기 → 장 후)

| 단계 | 길이 | 할 수 있는 것 |
|---|---|---|
| 장 전 | 30초 | 아침 뉴스·차트 보기, **장 전 카드**, 예약 주문 넣기. 바로 사기·팔기 ✕ |
| 정규장 | 1·3·5·10분 (방에서 고름) | 실시간 거래(5초 칸), 장중 속보, **장중 카드** |
| 빨리 감기 | 남은 칸을 10배속 (최대 약 20초) | 가격·예약 체결은 그대로 진행 |
| 장 후 결산 | 15초 | 손익·순위, 장 마감 시황 뉴스, 차트 다시 보기 |

- "장 마감" 버튼 → **"⏩ 빨리 감기"**. 장을 끝내지 않고 남은 흐름을 빠르게 재생
- 빨리 감기 시작 규칙: 1대1은 한 명이 누르면 90초 뒤, 둘 다 누르면 바로. 3인 이상은 ⅔ 이상이면 30초 뒤, 전원이면 바로. 시작 전까지 취소 가능
- 장 전·장 후도 전원이 "준비 완료"면 건너뜀. 아니면 시간이 끝나면 자동으로
- 혼자 연습: 빨리 감기는 바로, 장 후 결산은 "다음 날 시작"을 눌러야 넘어감
- 차트: 현재 점 옆 **"다음 변동까지 n초" 게이지**, 아래 축 **가상 장 시간 09:00~15:30**, 가격이 바뀌면 숫자가 살짝 깜빡임

## B. 뉴스 늘리기

- 아침 뉴스 2~4개, 장중 속보 1~3개
- 새 종류: 공시(자사주·계약·유상증자), 애널리스트 리포트(목표가), 해외 증시 마감(밤사이 미국장), 정책, SNS 루머
- 장 후: 장 마감 시황 기사 (오늘 업종·지수 움직임과 이유)
- 화면 위쪽 한 줄 뉴스 티커, 지난 뉴스는 날짜별로 보기

## C. 카드 개편

### 원칙
- **가격은 고정** (시작 1,000만원 기준, 비쌀수록 강함). 실력으로 번 돈은 그대로 쓸 수 있게
- **한 판(시작~끝) 구매 횟수 제한**을 카드마다 둠
- 강한 카드는 **무료로 나오지 않음**
- 카드마다 **쓸 수 있는 때**가 정해져 있음: 🟦 장 전 / 🟩 장중 / ⬜ 언제든 / 🛡 갖고만 있으면(자동) / ⏳ 당일 소멸(받은 날 안 쓰면 사라짐)

### 무료 카드 (1대1과 3인 이상을 다르게)

| | 1대1 | 3인 이상 |
|---|---|---|
| 시작 카드 | 1장 (정보·보너스 중에서) | 1장 (정보·보너스 중에서) |
| 무료 지급 | 5일마다 1장 | 5일마다 1장 |
| 무료로 나오는 방해 카드 | **없음** (상대가 한 명뿐이라 공짜 방해는 너무 결정적) | 수수료 폭탄·주문 지연만, 각 3% |
| 뒤처진 사람 보정 | 지고 있는 쪽이 보험·확률 리포트 확률 ↑ | 꼴찌가 정보 카드 확률 ↑ |
| 보유 한도 | 3장 | 3장 |

### 방해 제한 (괴롭힘 방지)

| | 1대1 | 3인 이상 |
|---|---|---|
| 내가 쓰는 방해 | 하루 1장 | 하루 1장 |
| 내가 맞는 방해 | 하루 1번까지 | 하루 1번까지 (여러 명이 몰아서 ✕) |
| 연속 공격 | 방해를 쓴 다음 날은 방해 ✕ (격일) | 같은 상대를 이틀 연속 ✕ |

### 기존 카드 처리
- 진행 중인 판은 기존 카드 규칙 그대로. **새로 만든 방부터** 새 카드 규칙 (방에 규칙 버전 저장)

## D. 주가 연관성

### 지금 있는 것 (확인함)
- 시장 전체 흐름(공통 요인)이 업종마다 민감도(베타)만큼 반영
- 금리·환율·유가 → 업종별로 다르게 영향
- 업종 뉴스 → 연관 업종으로 번짐, 기업 뉴스 → 같은 업종 다른 회사로 25% 번짐
- 지수 = 국내 종목들의 평균 움직임, ETF = 담은 종목 평균 × 배율(레버리지·인버스), 원유·달러 ETF = 유가·환율
- 미국 주식은 원화 환산 시 환율 반영, 미국 분위기가 한국에 40% 영향

### 부족한 것 → 개선
1. **장중 움직임이 따로 놂** (지금 5초 칸은 종목마다 독립) → 장중에도 시장·업종 공통 흐름을 먼저 만들고 종목이 따라가게. 지수·ETF 장중 칸은 종목 칸에서 계산
2. **미국장 → 다음 날 한국 시가**: 밤사이 미국장 결과가 다음 날 아침 갭으로 (해외 증시 마감 뉴스와 함께)
3. **지수는 시가총액 가중** (큰 회사가 더 크게 움직임)
4. **공급망 연결**: 회사 단위 연결 (예: 완성차 → 배터리·부품)
5. **장세**: 며칠씩 이어지는 상승장/하락장, 큰 하락 뒤 변동성 커짐
- 일별 가격이 바뀌므로 **새로 만든 방부터** 새 시장 (진행 중인 판은 그대로, 시장 버전 저장)

## G. 악용 시나리오
| 시도 | 막는 법 |
|---|---|
| 장 전에 바로 거래 | 서버가 단계 확인 후 거절 |
| 빨리 감기 직전 가격으로 거래 | 가격은 서버 시각의 칸 (빨리 감기 중엔 10배 빠른 칸) |
| 카드 구매 한도 넘기기 | 서버가 구매 기록으로 계산 |
| 다음 날 뉴스 미리 받기 | 장 전 시작 시각 전엔 화면 데이터에 없음 |
| 여러 명이 한 명 몰아치기 | 하루 1번만 맞음 |

## H. 완료 기준
- [ ] 장 전에는 바로 거래 거절, 예약은 됨 (단위 + e2e)
- [ ] 빨리 감기 중에도 모든 칸이 지나가고 예약이 칸에서 체결 (단위)
- [ ] 1대1/3인 이상 빨리 감기 규칙·취소 (e2e)
- [ ] 다음 날 뉴스는 장 전 시작 전 화면 데이터에 없음 (단위)
- [ ] 카드 구매 한도·사용 시점·당일 소멸·무료 확률(전설·방해 제외) (단위)
- [ ] 방해 하루 1번·연속 금지 (1대1, 3인) (단위)
- [ ] 확률 리포트는 35~75%만, 확정 정보 없음 (단위)
- [ ] 장중 칸: 같은 업종 종목끼리 상관, 지수 칸 = 종목 칸 가중 평균 (단위)
- [ ] 진행 중인 v1 방은 가격·카드 그대로 (단위)
- [ ] 이모지 대신 아이콘, 모바일 세로·가로·PC 옆 스크롤 없음·콘솔 에러 0 (브라우저)
