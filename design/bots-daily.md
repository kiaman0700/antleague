# 봇 대결 · 오늘의 도전

작성 2026-11-17 · 스킬: game-feature-spec · 상태: **승인 대기**

## 1. 한 줄 요약
- **봇전**: 사람을 기다리지 않고 봇(난이도 쉬움·보통·어려움)과 바로 한 판. 봇 수(1~5)·난이도·판 길이를 고름
- **커스텀 방에 봇 추가**: 방장이 빈자리에 봇을 넣어 '나 + 친구 + 봇 2명'처럼 함께
- **오늘의 도전**: 하루에 한 번, 모두 똑같은 시장으로 혼자 한 판 → 그날 점수표(회원)

---

## 2. 규칙

### 봇 난이도 (모두 '화면에 보이는 정보'만 씀 — 미래 가격·진실 여부·상대 거래는 모름)
사용자 기준(2026-11-17): 쉬움 = 초보도 거의 다 이김 · 보통 = 몇 판 해 본 사람이면 이김 · 어려움 = 상위 랭커가 아니면 이기기 어려움
| 난이도 | 이름 | 하는 일 | 시뮬 평균(10일) |
|---|---|---|---|
| 쉬움 | 새내기봇 | 악재 종목을 '싸다'며 사고, 조금 오르면 팔고 자주 갈아탐(수수료), 떨어진 건 버팀 | 약 -8% (지수만 들고 있어도 약 80% 이김) |
| 보통 | 개미봇 | 아침 뉴스·소문을 그대로 따라 사고 장 마감에 정리. 받은 카드는 씀 | 약 +7% |
| 어려움 | 고수봇 | 하루 10번 시장을 봄, 지난 정리 기사(시황·특징주)엔 안 속음, 수수료 폭탄 조심, 사건 찌라시가 좋은 쪽이면 발표까지 들고 감 | 약 +15% (보통을 약 72% 이김) |
- 카드를 사서 쓰는 봇은 시뮬에서 카드 값 때문에 오히려 약했음 → 어려움은 '판단'으로 강하게
- 사람이 일찍 마감해도 봇은 남은 칸을 '그 칸 시각'의 가격으로 움직임 (한순간에 몰아서 하지 않음)
- 봇이 움직이는 때: 하루에 3번(장 시작 직후·중간·끝 무렵). 장 전 시간엔 바로 '준비 완료'
- 봇은 **사람이 모두 장 마감을 누르면 그때 마감** → 봇 때문에 카운트다운이 시작되거나 사람을 기다리게 하지 않음
- 봇 이름 옆에 '봇' 표시 (사람과 헷갈리지 않게)

### 봇전 (새 메뉴)
- 로비 메뉴 '연습' 안에 **'봇전'** 칸 (휴대폰도 같은 곳). 기본값: 봇 1명·보통·10일·하루 1분
- 고르는 것: 봇 수 1~5, 봇마다 난이도(한 번에 '모두 보통' 같이도), 10/20일, 하루 1·3분
- **이 기기(브라우저)에서 돌아감** (연습처럼, 서버 안 씀 → 바로 시작·끊겨도 이어하기). 점수·랭킹 없음. 업적은 연습과 같게(그 판 결과 화면에만)
- 기본값: 봇전은 브라우저에서 (서버 기록이 필요하면 말씀해 주세요)

### 커스텀 방에 봇 추가
- 대기실 빈자리에 방장만 **'봇 추가'** → 난이도 고르기. 방장은 봇을 빼거나 바꿀 수 있음
- 봇은 늘 '준비 완료'. 사람+봇 최대 6명, **사람은 최소 1명**(방장)
- 봇이 있는 방은 커스텀(점수 없음). 매칭·랭킹전엔 봇 없음
- 카드 값·카운트다운 기준 인원: 봇도 한 명으로 셈(카드 값), 카운트다운은 사람만 셈
- 사람이 모두 나가면 방이 끝남 (봇만 남은 방은 지움)

### 오늘의 도전
- 매일 0시(한국 시간)에 새 시장. **모든 사람이 같은 시장**(같은 뉴스·가격)
- 혼자 한 판: **10일 · 하루 1분**(장 전 20초) · 시작 100만원 · 카드는 평소처럼(방해 카드는 상대가 없어 상점에 안 나옴)
- **계정마다 하루 한 번**. 시작하면 그날 기회를 쓴 것 (중간에 나가도 그 시점 재산으로 기록)
- 점수 = 마지막 날 수익률. 점수표: 그날 회원 상위 50명 + 내 순위. 게스트도 할 수 있지만 점수표엔 안 오름
- 장 마감을 누르면 바로 다음 날(혼자라서). 기본값: 빨리 넘기기 허용 (악용 7번 참고)

## 3. 서버가 정하는 것 / 화면에 보내는 것
| 값 | 어디서 | 화면에 |
|---|---|---|
| 봇 행동(사고팔기·카드) | 서버(커스텀 방) / 브라우저(봇전) — 봇 자신의 화면 데이터(`buildView(봇)`)만 보고 결정 | 다른 사람 거래처럼 **안 보임** (순위·수익률 구간만) |
| 봇 난이도·이름 | 서버 | 이름·'봇' 표시·난이도 (대기실) |
| 오늘의 도전 시드·salt | 서버 비밀(`HMAC(서버 비밀 키, 'daily:날짜')`) — room_secrets 에만 | **절대 안 보냄** (지금 규칙 그대로) |
| 오늘의 도전 점수 | 서버가 마지막 재산으로 계산 | 순위·닉네임·수익률(소수 1자리) |
- 화면 데이터에 새로 들어가는 것: `players[].bot`(봇이면 난이도), `room.kind`('bot'·'daily')
- 절대 안 들어가는 것: 봇의 보유 종목·거래·카드·전략 정보, 도전의 시드·salt·다른 사람의 진행 중 기록

## 4. DB 변경
- `033_bots.sql`: `players.bot_level smallint null`(1·2·3, null=사람), `players.bot_step int`(봇이 마지막으로 움직인 칸 — 두 요청이 동시에 와도 한 번만 움직이게 `update … where bot_step < 지금칸 returning`), 봇 자리는 `user_id null`
- `034_daily.sql`: `daily_runs(day date, user_id uuid, room_id uuid, ret real, finished bool, primary key(day, user_id))`, rooms.kind 에 'daily' 허용. 브라우저 권한 없음(서버만)
- 적용 전에도 서버가 죽지 않게: 칸·표가 없으면 '봇 추가'·'오늘의 도전'만 "준비 중이에요"로 거절

## 5. 진행 중인 게임
- 가격·뉴스 코드는 안 바꿈 → 진행 중 방 그대로. 봇의 무작위(쉬움 봇)는 **봇 전용 난수**(`seeded(salt:bot:봇id:날:칸)`) — 시장 난수와 섞이지 않음
- 규칙 버전은 그대로 v13 (봇은 '참가자'일 뿐 시장 규칙이 아님)

## 6. 화면
- **로비**: '연습' 메뉴에 '봇전'·'오늘의 도전' 칸 추가 (PC 위 메뉴·휴대폰 아래 탭 그대로, 새 탭 없음). '오늘의 도전' 칸엔 오늘 한 번 했는지·내 순위
- **봇전 만들기 창**: 봇 수(− 1 +), 난이도 3칸, 판 길이·하루 시간 → '시작'
- **대기실**: 빈자리에 '+ 봇 추가'(방장), 봇 자리엔 난이도·'빼기'
- **게임 화면**: 봇 이름 옆 작은 '봇' 표시 (순위표·점수판)
- **오늘의 도전 결과**: 결과 화면 아래 '오늘의 순위 n위 / 점수표 보기'
- 휴대폰 세로·가로·PC 모두 새 스크롤바 없이

## 7. 악용 시나리오와 막기
| 시나리오 | 막는 법 |
|---|---|
| 봇을 내 마음대로 움직이기·봇 자리에 요청 | 봇 행동은 서버만. 봇 player id 로 오는 요청은 없음(사람만 토큰), 봇 추가·빼기는 방장·대기 중일 때만 |
| 같은 순간 요청 여러 개로 봇이 두 번 거래 | `bot_step` 원자적 갱신으로 한 요청만 실행 |
| 봇으로 랭킹 점수 얻기 | 봇 있는 방은 ranked 불가(서버 확인) |
| 봇에게 방해 카드 몰빵해 이기기 | 평소 규칙 그대로(하루 한 번 등) — 봇도 방어 카드 씀(어려움) |
| 도전 여러 번 하기 | `daily_runs` 기본키(날짜·계정)로 한 번만, 시작할 때 먼저 기록 |
| 다른 계정으로 미리 보고 본 계정으로 하기 | 점수표는 회원만, 계정당 1회. 완전히 막을 수는 없음(같은 시장이 이 모드의 재미) — 대신 장 마감 뒤 '그날 가격'은 다음 날 0시 전엔 결과 화면에서도 남에게 공유 안 함 |
| 도전 시장 시드 맞히기 | 시드·salt 는 서버 비밀 HMAC, 화면엔 안 감 (지금 규칙) |
| 봇 많이 만들어 서버 부하 | 방당 봇 5명, 방 만들기 제한 그대로 |

## 8. 완료 기준
- [ ] 봇 3단계가 `buildView(봇)`만 보고 움직인다 — 미래 가격·진실 여부를 쓰지 않음 (단위 테스트)
- [ ] 시뮬레이터에서 쉬움 < 보통 < 어려움 순으로 승률이 오른다 (sim)
- [ ] 봇 행동은 같은 칸에 한 번만 (동시 요청 e2e)
- [ ] 봇은 사람이 모두 마감한 뒤에만 마감, 봇 때문에 카운트다운이 시작되지 않음 (단위·e2e)
- [ ] 다른 사람 화면 데이터에 봇의 거래·카드·보유가 없다 (단위 테스트 '정보가 새지 않는다')
- [ ] 커스텀 방: 방장만 봇 추가·빼기, 대기 중일 때만, 사람+봇 6명까지, 봇 있는 방은 ranked 아님 (e2e)
- [ ] 사람이 모두 나가면 봇 방이 정리된다 (e2e)
- [ ] 봇전: 브라우저에서 봇 1~5명과 시작·끝·결과까지 (브라우저)
- [ ] 오늘의 도전: 같은 날 두 계정의 시장이 같고, 날이 바뀌면 다르다 (e2e)
- [ ] 오늘의 도전: 계정당 하루 한 번, 두 번째 시작은 거절 (e2e)
- [ ] 오늘의 도전 화면 데이터에 시드·salt 없음 (단위·e2e)
- [ ] 점수표: 회원만, 시험 회원 제외, 상위 50 + 내 순위 (e2e)
- [ ] 휴대폰 세로·가로·PC 화면에서 새 칸이 넘치지 않음 (브라우저)

## 9. 순서 (나눠서 배포)
1. 봇 엔진(`src/engine/bots.ts`) + 시뮬로 난이도 맞추기 + **봇전(브라우저)** → 배포
2. 커스텀 방 봇 추가(서버·DB 033) → 배포
3. 오늘의 도전(서버·DB 034·점수표) → 배포
