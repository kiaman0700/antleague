# 미션

작성 2026-11-17 · 스킬: game-feature-spec · 상태: **완료** (보상 = 레벨·사진·칭호, 봇전 서버로 — 사용자 결정 2026-11-17)

## 1. 한 줄 요약
매일 바뀌는 **오늘의 미션 3개**와 **이번 주 미션 1개**를 깨면 경험치를 받아 **계정 레벨**이 오르고, 레벨에 따라 프로필 사진·칭호가 열린다. (게임 안 이득은 없음 — 공정성 유지)

## 2. 규칙
- 오늘의 미션: 매일 0시(한국)에 계정마다 3개 (아래 목록에서, 쉬움 2 + 보통 1). 이번 주 미션: 월요일 0시에 1개 (어려움)
- 미션 목록 (예시, 숫자는 시작값):
  | 미션 | 난이도 | 경험치 |
  |---|---|---|
  | 대결(일반전·랭킹전·커스텀) 1판 끝까지 하기 | 쉬움 | 30 |
  | 루머 감별기 1번 쓰기 | 쉬움 | 20 |
  | 예약 주문 1번 체결시키기 | 쉬움 | 20 |
  | 장중 속보가 뜬 종목 사기 | 쉬움 | 20 |
  | 오늘의 도전 하기 | 쉬움 | 30 |
  | 수익률 +3% 넘게 마감 | 보통 | 50 |
  | 봇전 보통 이상 이기기 | 보통 | 50 |
  | 다인전에서 3위 안 | 보통 | 50 |
  | 대결 3판 이기기 (이번 주) | 어려움 | 150 |
  | 고수봇 이기기 (이번 주) | 어려움 | 150 |
- 레벨: 레벨마다 필요한 경험치 100 + 20×(레벨−1). 레벨 5·10·15·20 에 프로필 사진, 10·20 에 칭호
- 회원만 경험치가 쌓임 (게스트는 미션 화면만 보고 '회원이 되면 쌓여요')

## 3. 서버가 정하는 것 / 화면에 보내는 것
| 값 | 어디서 | 화면에 |
|---|---|---|
| 오늘의 미션 고르기 | 서버 (`HMAC(비밀 키, 계정+날짜)` 로 섞음 — 계정마다 다름, 미리 알 수 없음) | 오늘 3개·이번 주 1개, 진행도 |
| 미션 달성 판정 | **서버가 끝난 판의 데이터(거래·카드·주문·결과)로 판정** — 화면이 '했어요'라고 보내는 값은 믿지 않음 | 달성 여부·받은 경험치 |
| 경험치·레벨 | 서버 | 레벨·다음 레벨까지 |

## 4. DB 변경 (`035_missions.sql`)
- `mission_days(user_id, day, ids text[], done text[])`, `mission_weeks(user_id, week, id, done)`, `profiles.xp int default 0` — 브라우저 권한 없음
- 판이 끝날 때(`maybeAdvance` 끝 부분) 그 판의 회원들에 대해 판정 → 한 번만(기본키·`done` 배열에 없을 때만 추가)

## 5. 진행 중인 게임
- 가격·규칙 변화 없음 (끝난 판을 읽기만)

## 6. 화면
- 로비 오른쪽(PC 소셜 칸 위) / 휴대폰 '더보기' 위: **미션 칸** — 오늘 3개 체크리스트(진행 막대), 이번 주 1개, 남은 시간, 레벨·경험치 막대
- 결과 화면: 이번 판으로 깬 미션 + 받은 경험치 (짧은 축하)
- 마이프로필: 레벨 표시, 레벨로 열리는 사진

## 7. 악용 막기
| 시나리오 | 막는 법 |
|---|---|
| 화면에서 '미션 완료' 보내기 | 완료 요청 자체가 없음 — 서버가 끝난 판으로만 판정 |
| 커스텀 방에서 둘이 짜고 빨리 끝내기 | 최소 조건(판이 '끝까지' 진행, 거래 1회 이상), 하루 경험치 상한(예: 300) |
| 브라우저 판(연습·봇전) 조작 | 기본값: **서버 판만 셈** (아래 결정 2) |
| 같은 판으로 두 번 받기 | (계정, 판) 기록으로 한 번만 |

## 8. 완료 기준
- [ ] 같은 날 같은 계정은 같은 미션, 날이 바뀌면 새 미션, 계정마다 다름 (단위)
- [ ] 화면 데이터에 미션 고르는 비밀값 없음 (단위 '정보가 새지 않는다')
- [ ] 판이 끝나면 조건을 채운 미션만 완료·경험치 (e2e)
- [ ] 같은 판·같은 미션으로 두 번 못 받음, 하루 상한 (e2e)
- [ ] 게스트는 경험치 안 쌓임 (e2e)
- [ ] 휴대폰·PC 미션 칸이 넘치지 않음 (브라우저)

## 9. 결정이 필요한 것
1. **보상**: 기본값 = 레벨·프로필 사진·칭호(겉모습만). 게임 안 이득(카드 등)은 공정성 때문에 비추천
2. **봇전도 미션에 셀지**: 지금 봇전은 브라우저에서 돌아서 조작이 가능해요. 기본값 = 봇전을 서버 판으로 옮겨서(커스텀 방처럼 봇과 바로 시작) 미션에도 셈. (옮기면 다른 기기에서도 기록·업적이 남음)
