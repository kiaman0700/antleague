# 주간 개미리그 설계서 (2026-11-18, 승인 전)

## 한 줄 요약
매주 월요일 0시(한국)에 회원을 실력과 상관없이 **20~30명씩 한 조**로 묶고, 그 주에 얻은 **경험치 순서**로 순위를 매겨 위는 한 단계 승급, 아래는 강등. 랭킹전을 안 하는 사람도 매주 겨룰 거리가 생김.

## 조사로 본 '보통' (design/v24-big-update.md C)
- 듀오링고 리그: 매주 약 30명 무작위 묶음, 주간 경험치 순, 위는 승급·아래는 강등, 10단계. 가장 꾸준히 오래 하게 만드는 장치로 꼽힘
- 피할 것: 밤새 경험치만 노가다하게 만들기, 죄책감 주는 알림 → 하루 경험치 상한(이미 있음: 판 600·미션 450)으로 노가다 막힘

## 규칙
| 항목 | 값 |
|---|---|
| 리그 단계 (아래 → 위) | 알개미 · 일개미 · 병정개미 · 정찰개미 · 여왕개미 · 황금개미 (6단계) — 개미 말고 다른 동물 안 씀 |
| 조 크기 | 최대 30명, 그 주에 처음 경험치를 얻은 순서대로 같은 단계의 빈 조에 들어감 |
| 점수 | 그 주(월 0시~일 24시)에 얻은 경험치 합 (판·첫 승·업적·미션 모두, 하루 상한 그대로) |
| 승급 | 조 안 1~5위 (조가 10명 미만이면 1~2위) |
| 강등 | 조 안 아래 5명 (조가 10명 미만이면 아래 1명). 알개미는 강등 없음 |
| 경험치 0 | 그 주에 하나도 안 얻으면 조에 안 들어감(순위 없음), 단계는 그대로 |
| 보상 | 주가 끝나면 '지난주 결과' 팝업(순위·승급/강등), 여왕개미 이상 도달하면 사진 테두리, 황금개미 1위는 칭호 '이번 주 황금개미' (사진·칭호만 — 경험치는 안 줌, 노가다 방지) |
| 대상 | **회원만** (게스트는 '회원가입하면 매주 리그에 들어가요' 안내 — 가입할 이유) |

## 서버가 정하는 것 / 화면에 보내는 것
- 서버만: 조 배정·점수·순위·승급/강등 계산. 경험치는 이미 서버만 씀(xp_log·add_xp)
- 화면에 보냄: 내 단계, 이번 주 내 조의 순위표(**닉네임·경험치·사진만**, 계정 id 없음), 승급/강등 선, 남은 시간
- 절대 안 보냄: 계정 id, 다른 조 정보, 시험 계정(조에 안 넣음)

## DB (052_league.sql, 여러 번 실행해도 안전)
- `league_tiers(user_id pk, tier smallint 0~5, updated_week date)` — 지금 단계
- `league_members(week date, user_id, group_id uuid, tier smallint, start_xp int, primary key (week, user_id))` — 그 주의 조, 시작 때 경험치(점수 = 지금 경험치 − 시작 경험치)
- `league_groups(id uuid pk, week date, tier smallint, size int)`
- 조 넣기는 DB 함수(`league_join`)로 잠그고 한 번에 — 동시에 여러 판이 끝나도 한 사람이 두 조에 들어가지 않게
- 테이블이 없으면(적용 전) 리그 칸은 숨김 — 서버가 죽지 않게

## 화면
- 로비 메뉴(PC 위 메뉴·휴대폰 더보기)에 '리그' — 내 단계 그림 + 조 순위표(승급 줄은 초록, 강등 줄은 빨강 선) + 남은 시간
- 판 결과 화면 '보상' 칸에 '이번 주 리그 n위 (+경험치)' 한 줄
- 월요일 첫 접속에 '지난주 결과' 팝업 한 번

## 악용 막기
- 경험치 하루 상한 그대로(판 600·미션 450) → 하루 종일 해도 한계
- 시험 계정·봇은 조에 안 넣음
- 점수는 서버의 경험치 차이로만, 화면이 보낸 값 무시

## 완료 기준
- [ ] 판이 끝나 경험치를 얻으면 그 주 조에 들어감(한 번만, 동시 요청에도) — e2e
- [ ] 조 순위표에 계정 id 없음 — e2e
- [ ] 주가 바뀌면 순위대로 승급·강등 — 단위 시험(계산 함수)
- [ ] 게스트에겐 안내만 — 화면
- [ ] 휴대폰·PC 리그 화면, 결과 화면 한 줄 — 화면 확인
