# 찬스 카드 2판 — 사지 않고 '골라 받기' (규칙 v27)

## 1. 한 줄 요약
카드 상점(현금으로 사기)과 5일마다 받던 무료 카드를 없애고, 롤토체스 증강처럼 **정해진 날 아침에 카드 3장 중 1장을 골라** 받는다. 모두 같은 날 같은 횟수만 고르므로 돈 많은 쪽이 카드도 많이 사는 일이 없다.

## 2. 규칙

| 판 길이 | 고르는 날 (그날 장 전 ~ 장 마감 전) | 횟수 |
|---|---|---|
| 5일 (번개 봇전) | 1일차 · 3일차 | 2번 |
| 6~12일 (10일 신속 등) | 1일차 · 판의 35% 지점 · 65% 지점 (10일: 1·4·7일차) | 3번 |
| 13일 이상 (20일 일반) | 1일차 · 30% · 55% · 80% 전 (20일: 1·6·11·16일차) | 4번 |

- 마지막 20% 구간에는 고르지 않음 (써먹을 시간이 없어서).
- **3장 보기**: 사람마다 따로 뽑지만 늘 **종류가 섞임** — 정보 1장 + 방해 1장 + 방어·보너스 1장 (혼자 하는 판은 방해·방어 대신 정보 2장 + 보너스). 같은 카드 2장은 안 나옴.
- **다시 뽑기**: 고를 때마다 1번 (3장 모두 새로). 돈은 들지 않음.
- **건너뛰기**: 가능. 건너뛰면 다음 고르기 때 다시 뽑기 +1.
- **시간 안에 안 고르면**: 그날 장 마감(또는 하루 끝)에 서버가 3장 중 하나를 정해 줌. 기다려 주지 않음 — 고르기 때문에 판이 멈추지 않음.
- **들고 있기**: 지금처럼 5장까지. 꽉 찼으면 고르기 창에서 "가진 카드 1장 버리고 받기" 또는 "건너뛰기".
- **쓰기 규칙은 지금 그대로**: 같은 카드 한 판 2번까지, 정보 카드 하루 1장, 같은 날 한 사람에게 방해 1번, 방패·반사 거울 자동.
- **카드 값이 없어짐**: 현금은 주식에만 씀. 용돈 봉투는 보기에 나올 수 있음(지금처럼 공개 확률).
- 1일차 시작 카드(START_CARDS)도 1일차 고르기로 대신함.

기본값 (바꾸려면 말씀해 주세요)
- 등급(롤토체스의 실버·골드·프리즘)은 **1판에서는 넣지 않음** — 지금 카드 12장이 모두 한 번 쓰는 카드라, 등급을 넣으려면 '판 끝까지 가는 효과' 카드를 새로 만들고 시뮬로 금액을 맞춰야 해서 다음 단계로.
- 상대가 무엇을 골랐는지는 숨김 (지금처럼 상대 카드는 안 보임). 판이 끝난 뒤 결과 화면에서만 공개.

## 3. 서버가 정하는 것 / 화면에 보내는 것

| | 서버만 | 화면(내 것만) |
|---|---|---|
| 보기 3장 | `seeded(salt:pick:자리:n:다시뽑기수)` 로 서버가 만듦 (salt 는 room_secrets) | 지금 고를 차례면 **내** 보기 3장, 남은 다시 뽑기 수, 마감 시각 |
| 고른 카드 | 서버가 "내 보기 안에 있는지" 확인 후 저장 | 내 손패 |
| 상대 | 무엇을 골랐는지·보기 | **"고르기 끝냄" 여부도 보내지 않음** (고르는 데 걸린 시간으로 성향이 드러나지 않게) |

절대 넣지 않는 것: 상대 보기·상대 고른 카드, 다른 날 보기(미래), salt·seed.

## 4. DB 변경 — `supabase/063_card_picks.sql` (여러 번 실행해도 안전)
- `items.action` 허용 값에 `'pick'`(고름), `'reroll'`(다시 뽑기), `'skip'`(건너뜀), `'drop'`(버림) 추가. payload `{n: 몇 번째 고르기, kind?}`.
- 같은 고르기 두 번 방지: `(player_id, (payload->>'n')) where action in ('pick','skip')` 유니크.
- 적용 전 서버는 예전 규칙 방(v26 이하)만 쓰므로 죽지 않음. v27 방 만들기는 칸이 생긴 뒤에만.

## 5. 진행 중인 게임
- 규칙 버전 **v27**. v26 이하 방은 상점·무료 카드 그대로 (버전 분기).
- 가격·뉴스는 v26 과 같음 (카드 쪽만 바뀜) — 지문 테스트로 확인.
- 튜토리얼(늘 최신 규칙)은 카드 2장(감별기·방패)을 그대로 쥐여 주고 시작 — 고르기 단계는 튜토리얼에서 1번 보여 줌(1일차).

## 6. 화면
- **고르는 날**: 장 전 시간 시작 때 화면 가운데 **카드 3장 창**(휴대폰은 아래에서 올라오는 시트) — 카드 그림·이름·한 줄 설명, [이걸로] 버튼, 아래 [다시 뽑기 (1)] [건너뛰기]. 닫아도 카드 칸에 '오늘 고를 카드가 있어요' 배지로 다시 열 수 있음.
- **카드 칸**: '상점' 버튼·값 없애고, "다음 카드 고르기: 4일차" 한 줄.
- **카드 도감·공부 탭**: "카드는 사지 않고 정해진 날 골라 받아요" 설명.
- PC·휴대폰 모두 기존 카드 그림(ToonIcon) 그대로.

## 7. 악용 시나리오와 막는 법
| 시도 | 막는 법 |
|---|---|
| 보기에 없는 카드를 보냄 | 서버가 보기를 다시 계산해 확인, 아니면 400 |
| 다시 뽑기를 여러 번 | 남은 수를 기록에서 세서 0이면 409 |
| 같은 고르기를 두 번(동시 요청) | DB 유니크 + 요청 번호(reqId) |
| 고르기 날이 아닌데 고름 / 지난 고르기를 나중에 | 서버가 오늘이 고르는 날이고 그 n번째가 아직 안 끝났는지 확인 |
| 새로고침으로 보기 바꾸기 | 보기는 seed 로 정해져 새로고침해도 같음 |
| 일부러 안 골라 나중에 유리한 것 고르기 | 그날이 끝나면 서버가 자동으로 정함, 다음 날엔 못 고름 |
| 상대 고른 카드 엿보기 | 화면 데이터에 없음 (정보 새지 않음 테스트) |

## 8. 완료 기준
- [ ] 10일 판에서 고르기는 1·4·7일차 3번, 5일은 2번, 20일은 4번 (단위)
- [ ] 보기 3장은 정보·방해·방어/보너스가 섞이고 중복 없음, 혼자 판엔 방해·방어 없음 (단위)
- [ ] 같은 salt·자리·n 이면 보기가 같고, 다시 뽑기하면 달라짐 (단위)
- [ ] 보기에 없는 카드를 고르면 거절 (e2e)
- [ ] 다시 뽑기 1번 쓰면 더는 안 됨, 건너뛰면 다음 고르기에 2번 (e2e)
- [ ] 그날 안 고르면 다음 날 손에 보기 중 1장이 들어와 있음 (e2e)
- [ ] 5장 꽉 찼을 때 버리고 받기 / 건너뛰기만 됨 (e2e)
- [ ] 상대 화면 데이터에 내 보기·고른 카드가 없음 (단위 "새지 않음" + e2e)
- [ ] v27 방에서 카드 사기(buyItem)는 거절, v26 방은 그대로 됨 (e2e)
- [ ] v26 이하 가격·뉴스 지문이 그대로 (단위)
- [ ] 봇도 고르기를 함(쉬움은 아무거나, 보통·어려움은 정보 우선) (단위)
- [ ] 시뮬: 카드 고르기 전후로 뉴스 잘 읽는 쪽 승률이 크게 안 바뀜 (sim/cards2)
- [ ] 휴대폰 세로·가로, PC 에서 고르기 창이 잘리지 않고 버튼이 가려지지 않음 (기기 시험)
