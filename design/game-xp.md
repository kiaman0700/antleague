# 게임 경험치 (미션 말고 판을 끝내도 레벨이 오름)

작성 2026-11-17 · 스킬: game-feature-spec · 상태: **승인 대기**

## 1. 한 줄 요약
미션뿐 아니라 **대결을 끝까지 하면** 경험치를 받음. 랭킹전·일반전은 같게, 봇전은 조금, 커스텀(친구끼리 방)은 없음.
레벨은 메뉴바 내 프로필(마우스 올리면)·마이프로필에서 봄. 미션 팝업엔 '오늘 받은 경험치'만.

## 2. 규칙 (회원만 · 끝까지 함 · 거래 1번 이상 · 판마다 한 번)
| 판 종류 | 끝내기 | 순위 보너스 | 비고 |
|---|---|---|---|
| 랭킹전 | 40 | 1위 +30 · (3인 이상) 2위 +10 | |
| 일반전 | 40 | 1위 +30 · (3인 이상) 2위 +10 | 랭킹전과 같음 |
| 봇전 | 10 | 1위 +5 (어려움 봇이 있으면 +10) | 혼자 반복 방지로 작게 |
| 오늘의 도전 | 20 | — | 하루 한 번 |
| 커스텀 방·친구 1대1 | 0 | — | 짜고 치기 방지 |
| 기권한 판 | 0 | — | |

**더 받을 거리 (아이디어)**
- **오늘 첫 승 +50**: 하루 처음 랭킹전·일반전 1위 (매일 들어올 이유)
- **처음 따는 업적 +20**(업적마다 한 번): 새 업적을 열 때
- **연속 출석**은 넣지 않음 — 들어오기만 해도 받는 건 판을 안 해도 돼서 레벨 의미가 약해짐

**상한**: 판 경험치는 하루 600 (미션 300 과 따로). 봇 반복으로 레벨을 올리는 걸 막음.
- 대략: 일반전 하루 5판·2승 = 40×5 + 30×2 + 첫 승 50 = 310

## 3. 서버가 정하는 것 / 화면에 보내는 것
- 판정·지급은 판이 끝날 때 서버(`maybeAdvance` → 지금 미션 판정과 같은 자리)가 서버 데이터로만. 화면이 '경험치 줘' 요청을 보낼 길은 없음
- 같은 판은 `mission_rooms`(계정, 판) 한 번만 규칙을 그대로 씀 → 미션과 함께 한 번에 판정
- 화면에 보내는 것: 내 경험치·레벨, 결과 화면에 '+70 경험치(끝내기 40 · 1위 30)', 오늘 받은 판 경험치/600
- 보내지 않는 것: 다른 사람의 경험치 내역, 계정 id

## 4. DB 변경
- `039_game_xp.sql`: profiles 에 하루 판 경험치 칸(`game_xp_day`, `game_xp_today`) 또는 `xp_log`(계정, 날짜, 종류, 양) 표 — 상한 계산용. 여러 번 실행해도 안전하게. 적용 전엔 서버가 판 경험치만 건너뜀(미션은 그대로)

## 5. 진행 중 게임 영향
- 가격·규칙 무관. 배포 뒤 끝나는 판부터 적용

## 6. 화면
- 메뉴바 프로필 팝업: Lv·막대(지금도 있음) + '오늘 판 경험치 120/600'
- 결과 화면: 미션 칸 위에 받은 경험치 한 줄. 레벨이 오르면 'Lv.4 달성' 표시
- 휴대폰: 위 머리줄 프로필 사진을 누르면 같은 팝업

## 7. 악용과 막는 법
- 봇전 반복 → 10~20 으로 작게 + 하루 상한 + 봇전 시간당 20판 제한(이미 있음)
- 친구끼리 짜고 이기기 → 커스텀·친구 1대1 은 0. 매칭 판만
- 거래 없이 방치 → 거래 1번 이상이어야 함, 기권 0
- 동시 요청으로 두 번 받기 → (계정, 판) 기본키로 한 번만

## 8. 완료 기준
- [ ] 랭킹전·일반전 끝 → 같은 경험치 (e2e)
- [ ] 봇전은 작게, 커스텀·기권·거래 없음은 0 (단위 + e2e)
- [ ] 같은 판 두 번 판정해도 한 번만 (e2e)
- [ ] 하루 상한 600 넘지 않음 (단위)
- [ ] 화면 요청으로 경험치를 줄 수 없음 (injection)
- [ ] 결과 화면·프로필 팝업에 보임 (브라우저)
