# 기기 종류로 화면 고르기 (창 크기 대신)

작성 2026-11-17 · 스킬: game-feature-spec · 상태: **2판 완료** (사용자 요청: 설정의 '화면 종류' 고르기 빼기, 폴더블 따로, 터치 노트북은 PC, 그 밖 기기도 고려)

## 1. 한 줄 요약
창 폭이 아니라 **기기 자체**(PC·태블릿·휴대폰·폴더블)를 단서 여러 개로 알아내 그 기기용 화면을 씀.
PC 는 창을 줄여도 PC 화면(900px 아래는 가로 스크롤 — 사용자 결정), 휴대폰은 가로로 눕혀도 휴대폰 화면.

## 2. 정확한 기기 이름을 알 수 있나? (사용자 질문)
- 대부분 **아니요** — 브라우저가 개인정보 때문에 숨김. 아이폰·아이패드 사파리는 기기 이름을 안 주고, 아이패드는 'Mac' 인 척함
- 안드로이드 크롬은 따로 물으면 모델명(예: SM-F946N = 갤럭시 폴드5)을 줌 (비동기, 크롬 계열만)
- 그래서 **단서 여러 개를 합쳐 '종류'** 를 정함 → 종류는 거의 정확

## 3. 판단 순서 (먼저 맞는 것) — 입력 장치(마우스냐 터치냐)보다 **기기 자체**를 먼저 봄
| 순서 | 단서 | 결과 |
|---|---|---|
| 0 | 주소 `?device=` (시험용, 그 창에서만, 저장 안 함) | 그대로 |
| 1 | TV·게임기 브라우저 (SmartTV·Tizen·webOS·PlayStation·Xbox…) | PC |
| 2 | 크롬이 알려 주는 기기 종류(form factor): Tablet / Mobile / Desktop | 태블릿 / 휴대폰 / PC |
| 3 | 브라우저 정보: iPhone·iPod → 휴대폰, iPad → 태블릿, 'Mac'인데 터치 지점 2개 이상 → 아이패드(태블릿), Android + Mobile → 휴대폰, Android(Mobile 없음) → 태블릿 | |
| 4 | 브라우저 정보: Windows·Mac·리눅스·크롬북 → **PC** (터치 노트북·2in1·삼성 DeX 포함) | PC |
| 5 | (단서 없음) 터치 지점이 있고 화면 짧은 쪽 < 600 → 휴대폰, ≥ 600 → 태블릿, 그 밖 PC | |
| ★ | **폴더블**: 휴대폰으로 판단됐는데 지금 기기 화면이 거의 정사각형(짧은 쪽/긴 쪽 ≥ 0.7)이고 짧은 쪽 ≥ 600 → **펼친 상태**, 아니면 접힌 상태(휴대폰). 크롬이 모델명을 주면(갤럭시 폴드·픽셀 폴드 등) 폴더블로 확정 | 펼침 = 태블릿 화면 · 접힘 = 휴대폰 화면 |

- 태블릿에 **마우스를 연결해도** 기기는 태블릿 → 태블릿 화면 (예전 방식은 PC 로 잘못 볼 수 있었음)
- **터치되는 노트북**은 윈도우·맥이 보이므로 늘 PC
- 폴더블을 접고 펼치면 화면 크기가 바뀜 → 그때마다 다시 판단해 바로 바뀜 (PC 는 창 크기가 바뀌어도 그대로 PC)

## 4. 기기별 화면
| 기기 | 화면 |
|---|---|
| PC | 늘 PC 화면. 900px 아래는 가로 스크롤 |
| 태블릿 | 세로: 태블릿 화면(목록+차트 나란히·아래 탭) · 가로: PC 화면(터치용) |
| 폴더블 펼침 | 태블릿 화면 (`data-fold="open"` 표시도 붙여 필요하면 따로 다듬음) |
| 휴대폰·폴더블 접힘 | 휴대폰 화면(세로·가로) |

## 5. 뺀 것
- 설정의 '화면 종류' 고르기 (사용자: 별로) — 판단을 똑똑하게 하는 쪽으로. 시험용 `?device=` 는 남김(저장 안 됨, 화면 고르기만)

## 6. 서버·DB·보안
- 서버·DB 변경 없음. 기기 단서는 브라우저 안에서만 쓰고 서버로 안 보냄. 모델명을 묻는 것도 브라우저 안에서만

## 7. 시험
- 단위: 단서 조합별 판단(아이폰·갤럭시·아이패드·아이패드+마우스·안드로이드 태블릿·폴드 접힘/펼침·터치 노트북·DeX·TV·맥)
- 기기 흉내 e2e(`npm run e2e:devices`): 위 기기 + 폴드 접힘(344×882)·펼침(884×1104)·터치 노트북(윈도우+터치) 추가
- 실제 기기: 배포 뒤 사용자 휴대폰·태블릿

## 8. 완료 기준
- [ ] PC(마우스) 창 800px → PC 화면
- [ ] 터치 노트북(윈도우 + 터치) → PC 화면
- [ ] 아이패드 + 마우스(Mac 처럼 보임 + 터치) → 태블릿 화면
- [ ] 갤럭시 폴드 접힘 → 휴대폰, 펼침 → 태블릿 화면, 그 자리에서 바뀜
- [ ] 휴대폰 가로(932) → 휴대폰 화면
- [ ] 설정에 '화면 종류' 없음, `?device=` 는 시험용으로 동작
- [ ] 모든 기기 × 화면 가로 넘침 0 (devices.mjs), 단위·빌드·e2e 통과
