## 3. 할 일

### ② 가입 동의 — 필수/선택 분리
- 가입 칸에 **[필수] 만 14세 이상**, **[필수] 이용약관 동의**, **[필수] 개인정보 수집·이용 동의** 세 칸 + **전체 동의** 칸
- [선택] 항목은 **만들지 않음** — 지금 마케팅 알림 등 선택으로 받는 정보가 없기 때문 (없는 선택 동의를 만들면 오히려 잘못). 나중에 선택 정보가 생기면 그때 [선택] 칸 추가
- 각 동의 옆 '보기'로 전문을 열 수 있게
- 서버: `agreeTerms` 도 확인 (빠지면 가입 거절), 동의한 약관 판(版) `terms_version` 을 회원 정보에 저장 (DB `031_consent.sql`, 칸 없으면 저장만 건너뜀)

### ③ 모든 화면 아래 법적 안내 줄
- 로비 모든 메뉴 아래: **개인정보처리방침 · 이용약관 · 의견 보내기** + 운영자 정보 한 줄
- 운영자 정보: `운영자 이준엽 · 문의 kiaman0700@naver.com` (이미 공개 동의된 값, `VITE_OPERATOR_CONTACT`)
- 사업자 정보: **사업자 등록이 없으면 넣지 않음** (없는 번호를 지어내면 안 됨). 등록하면 상호·대표·사업자번호·주소를 넣는 자리만 만들어 둠
- '개인정보 처리 안내' → 법적 이름인 **'개인정보처리방침'** 으로, 시행일 표시
- **이용약관** 새로 작성 (모의 투자 게임 — 실제 돈·투자 아님, 계정·금지 행위·서비스 변경·책임 한계·만 14세 이상). 초안이라 사용자가 읽고 고칠 수 있게

### ⑥ 시험/실제 데이터 분리 — 기본값: 시험용 Supabase 프로젝트를 따로
- Supabase 무료 요금제는 프로젝트 2개까지 무료 → **시험용 프로젝트(서울)** 를 하나 더 만들고, 로컬 서버·자동 시험은 그쪽을 씀. 실제 사이트(Vercel)는 지금 프로젝트 그대로
- 시험용 프로젝트에 같은 스키마·마이그레이션 적용 (`scripts/move-region.mjs schema` 재사용)
- **사용자가 할 일**: Supabase 에서 새 프로젝트 만들기 → 주소·키를 알려 주기 (또는 화면 안내대로 `.env.local` 에 넣기)
- 그동안 실제 DB 에 쌓인 시험 데이터 정리: 시험 회원 3명·자동 시험이 만든 계정·방을 지우는 SQL (어느 것이 시험인지 확실한 것만: e2e 계정 목록 파일·시험 닉네임 규칙)

### ⑥ 매일 백업 — 기본값: 이 컴퓨터에서 매일 자동 백업
- `npm run db -- backup` → 표 전체를 날짜 붙은 파일로 내려받아 `backups/` (git 에 안 올림, 30일 지난 것 지움)
- Windows 작업 스케줄러에 매일 새벽 4시 등록 (컴퓨터가 켜져 있을 때)
- 다른 방법: Supabase Pro($25/월)로 올리면 Supabase 가 매일 백업(7일 보관)을 해 줌
