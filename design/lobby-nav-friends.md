# 설계서: 메뉴(네비) · 게스트 안내 · 친구 · 함께 하기

## 1. 한 줄 요약
홈이 "게임 런처"처럼 바뀝니다. 왼쪽(PC)·아래(모바일) 메뉴로 랭킹전 / 일반전 / 커스텀 / 연습 / 친구 / 랭킹 / 기록을 오가고,
닉네임은 처음 한 번만 정합니다(회원은 가입 때, 게스트는 "게스트로 시작" 때). 회원끼리는 친구를 맺고, 방에 초대하고, 1대1을 신청하고, 일반전을 같이 찾을 수 있습니다.

## 2. 단계 (한 번에 다 하지 않고 4단계로 나눠 배포)
| 단계 | 내용 |
|---|---|
| 1 | 메뉴(네비) + 게스트 시작 안내 + 홈·방 들어가기에서 닉네임 입력 칸 없애기 |
| 2 | 친구 (신청·수락·거절·삭제·차단, 접속 중 표시) |
| 3 | 친구 초대 (커스텀 방으로 초대) + 친구에게 1대1 신청 |
| 4 | 일반전 같이 찾기 (파티) |

## 3. 화면 구조
**메뉴 항목**: 🏆 랭킹전 · ⚔️ 일반전 · 🛠 커스텀(방 만들기·방 찾기·코드로 입장) · 🎓 연습(혼자 연습·튜토리얼·도감) · 👥 친구 · 📊 랭킹 · 📜 기록·업적
맨 위(또는 메뉴 맨 위)에 내 프로필 칩(회원) / "로그인" 버튼(게스트). 친구 신청·초대가 오면 메뉴의 친구 칸에 숫자 배지.

| 기기 | 메뉴 위치 |
|---|---|
| PC (넓은 화면) | 왼쪽 세로 메뉴바 (아이콘 + 글자), 오른쪽에 고른 화면. 친구 목록은 PC에선 오른쪽 좁은 칸에 항상 보이게 (롤 클라이언트처럼) — 1280px 이상일 때만 |
| 태블릿 가로 | 왼쪽 메뉴바 (아이콘 + 작은 글자) |
| 태블릿 세로·모바일 | 화면 아래 탭바 5칸: 랭킹전 · 일반전 · 커스텀 · 친구 · 더보기(연습·랭킹·기록·설정) |

주소도 메뉴마다 따로: `/ranked` `/casual` `/custom` `/practice` `/friends` `/ranking` `/records` (뒤로가기 그대로 동작). `/` 는 마지막에 본 메뉴(처음엔 일반전).
화면 모드(초보/일반/커스텀)는 "더보기 → 설정"과 프로필 쪽으로 옮김 — 홈을 차지하지 않게.

## 4. 게스트 시작 안내 (닉네임은 그때 딱 한 번)
로그인하지 않은 사람이 온라인 기능(매칭·방 만들기·방 들어가기)을 처음 누르면 안내 창:

| | 게스트 | 회원 (무료, 아이디·비밀번호만) |
|---|---|---|
| 일반전·커스텀 방 | ✅ | ✅ |
| 랭킹전·랭킹 등록 | ❌ | ✅ |
| 친구·초대·같이 찾기 | ❌ | ✅ |
| 기록 보관 | 이 기기·이 브라우저에만 (기록 지우면 사라짐) | 어느 기기에서나 로그인하면 그대로 |
| 닉네임 | 다른 사람과 겹칠 수 있음, 이름 옆 "게스트" | 나만 쓰는 닉네임, 회원 표시 |

버튼: [회원가입] [로그인] [게스트로 시작] → 게스트로 시작을 누르면 그때만 닉네임 입력(1~10자).
- 게스트 닉네임은 이 기기에 저장, 더보기 → 설정에서 바꿀 수 있음
- 기본값: **게스트 닉네임은 회원 닉네임과 같을 수 없음** (회원 사칭 방지, 서버가 확인)
- 혼자 연습·튜토리얼은 안내 없이 바로 (닉네임 "나")
- 방 만들기·코드 입장·방 찾기 화면의 닉네임 칸은 없앰 (서버가 회원=프로필 닉네임, 게스트=저장된 닉네임 사용)

## 5. 친구 (회원만)
- 친구 추가는 **닉네임으로** 검색 (아이디는 절대 안 보임 — 지금 규칙 그대로). 정확히 같은 닉네임만 찾음(목록 훑기 불가)
- 신청 → 상대가 수락/거절. 삭제·차단 가능. 차단하면 신청·초대·1대1 신청이 오지 않음 (차단 사실은 상대에게 안 보임)
- 친구 최대 100명, 신청은 1시간에 20번까지, 받은 신청은 7일 지나면 사라짐
- 친구에게만 보이는 상태: 접속 중(2분 안에 활동) / 게임 중 / 오프라인. **친구가 아닌 사람에겐 아무 상태도 안 보임**
- 알림은 실시간 대신 홈에서 10초마다 확인 (지금 Realtime 은 방 변경만 받음 — 보안상 그대로)

## 6. 함께 하기 — 고민하신 부분에 대한 제안 ★
| 모드 | 친구와 같이 | 이유 |
|---|---|---|
| 일반전 1대1 | **"1대1 신청"** 버튼 → 수락하면 바로 시작 (신속/일반 고름, 점수 없음) | 둘이 하는 건 그냥 친선전 |
| 일반전 다인전 | **파티 최대 2명**까지 같이 찾기. 파티는 **4인 방에만** 들어가고, 한 방에 파티는 최대 2팀 (2+2 또는 2+1+1) | 3명 파티가 1명을 괴롭히는 판이 안 생기게. 그리고 이미 있는 규칙 "같은 날 한 사람에게 방해 카드는 한 번만"이 있어서 두 친구가 한 명을 같이 때려도 하루 1번만 맞음 |
| 랭킹전 (1대1·다인전) | **파티 불가, 혼자만**. 그리고 매칭이 **친구끼리는 같은 랭킹전 방에 넣지 않음** + **같은 인터넷(IP)에서 접속한 계정끼리도 같은 방에 안 넣음**(부계정 점수 몰아주기 방지) + 이미 있는 "같은 두 사람 하루 3판까지만 점수" | 친구와 랭킹전 = 점수 조작 위험. 동시에 대기열에 넣어 같은 방을 노리는 것도 막힘 |
| 커스텀 방 | 친구 초대 버튼 (초대받은 사람은 비밀번호 없이 입장, 초대는 5분 뒤 만료) | 점수 없음, 자유롭게 |

※ 같은 인터넷 제한 때문에 같은 집·같은 학교 와이파이 친구는 랭킹전에서 서로 안 만남 (일반전·커스텀은 상관없음). IP는 지금처럼 비밀값으로 섞은 해시만 저장.

## 7. 서버가 정하는 것 / 화면에 보내는 것
| 화면에 보냄 | 절대 안 보냄 |
|---|---|
| 친구 닉네임·칭호·점수·상태(친구에게만) | 아이디, 로그인 주소, user id, IP 해시 |
| 받은 신청·초대 (보낸 사람 닉네임, 방 제목) | 내가 누구에게 차단당했는지, 상대가 내 신청을 거절했는지(그냥 "대기 중"으로 두고 7일 뒤 사라짐) |
| 파티원 닉네임·준비 상태 | 친구가 아닌 사람의 접속 여부 |
친구 관계·초대·파티 확인은 모두 서버(`/api/game`)에서. 초대 수락 시 서버가 초대가 진짜 나에게 온 것인지·만료 전인지·방이 아직 대기 중인지 다시 확인.

## 8. DB 변경 (`018_social.sql`, 여러 번 실행해도 안전)

- 모두 RLS + 브라우저 권한 회수 (서버만 읽고 씀). 표가 아직 없으면 서버는 빈 목록을 돌려줌

## 9. 진행 중인 게임 영향
게임 규칙·가격은 그대로 (로비만 바뀜). 진행 중인 방에 영향 없음.

## 10. 악용 시나리오와 막는 법
- 남의 닉네임 사칭 → 게스트는 회원 닉네임 금지, 회원 표시 유지
- 친구 신청 폭탄 → 1시간 20번, 차단, 7일 만료
- 닉네임으로 회원 목록 훑기 → 정확히 일치만, 1분 20번 제한
- 초대 위조(남의 방에 끼어들기) → 서버가 초대 행을 확인, 1회용·5분 만료
- 랭킹전 짜고 치기 → 파티 불가 + 친구·같은 IP 분리 + 하루 3판 제한 + 기권 꼴찌
- 다인전 다구리 → 파티 2명·4인 방만·방당 파티 2팀 + 방해 카드 하루 1회
- 파티장이 나가면 → 파티 해산, 대기표 취소

## 11. 완료 기준
- [ ] 홈·방 만들기·방 찾기·코드 입장에 닉네임 입력 칸이 없다 (화면)
- [ ] 게스트가 처음 온라인 기능을 누르면 안내 창이 뜨고, "게스트로 시작"에서만 닉네임을 받는다 (화면)
- [ ] 게스트 닉네임이 회원 닉네임과 같으면 서버가 거절 (e2e)
- [ ] PC 왼쪽 메뉴 / 모바일·태블릿 세로 아래 탭바, 메뉴마다 주소가 다르고 뒤로가기 동작 (화면, 375·768·1024·1280·1920)
- [ ] 친구 신청·수락·거절·삭제·차단 (e2e), 친구가 아니면 상태가 안 보임 (e2e)
- [ ] 친구 관련 응답에 아이디·user id 가 없다 (e2e "정보가 새지 않는다")
- [ ] 초대받은 사람만, 5분 안에, 한 번만 입장 (e2e)
- [ ] 1대1 신청 수락 → 둘이 바로 시작, 점수 반영 없음 (e2e)
- [ ] 랭킹전에서 친구·같은 IP 끼리는 같은 방에 안 들어감 (단위 테스트 + e2e)
- [ ] 다인전 파티는 최대 2명, 4인 방에만, 방당 파티 2팀 이하 (단위 테스트)
