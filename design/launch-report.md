# 정식 출시 작업 결과 (2026-11-20)

## 1. 출시 플랫폼: 웹 + 설치형 웹앱으로 지금 정식 출시 → 다음은 구글 플레이
- 비용 0, 링크 하나로 친구와 바로 대결(우리 게임의 핵심), 휴대폰 이용자 중심, 업데이트 즉시 반영
- 구글 플레이(등록비 25달러)는 같은 웹을 앱으로 감싸 올리는 준비를 끝내 둠 → `design/google-play-twa.md`
- 스팀(100달러·PC·영어권)·앱스토어(99달러/년·심사 위험)는 지금은 추천 안 함 → `design/launch-plan.md`

## 2. 오늘 바꾼 것
**출시 준비**
- 인터넷이 끊기면 빈 화면 대신 안내 화면(서비스 워커 — 게임 코드는 저장 안 해서 업데이트 꼬임 없음)
- 설치 창이 스토어처럼: 앱 바로가기 3개(일반전·연습·랭킹전), 분류, 스크린샷 5장
- 개인정보처리방침·이용약관 바로 열리는 주소: /privacy · /terms (스토어 등록 필수)
- 스토어 글·등급 설문 답·데이터 보안 답·대표 그림(1024×500) 준비
- 수익 구조 설계: 실력에 영향 없는 꾸미기만, 뽑기(확률형) 없음, 광고 없음, 단계별 계획 → `design/monetization.md`

**사운드 (새로)**
- 배경 음악: 파일 없이 그 자리에서 합성(저작권·용량 0). 로비는 잔잔한 로파이, 장 전은 고요한 패드, 장중은 박자, 카운트다운은 더 빠르게, 결과 화면은 끔
- 큰 알림이 날 땐 음악이 잠깐 작아짐, 창을 벗어나면 멈춤, 장이 열릴 때 종소리
- 설정에서 음악·효과음 따로 켜고 끄기 + 크기 조절, 게임 안 소리 버튼은 둘 다
- 아이폰은 무음 스위치를 따르고 듣던 음악 앱과 섞여 나옴

**처음 온 사람**
- 시작 창: 표부터 보여 주던 것을 '바로 시작하기' 한 번으로(가입은 나중에도 기록이 이어짐), 차이표는 접어 둠
- 닉네임은 무작위 이름이 미리 채워져 그대로 시작 가능
- 튜토리얼: 작은 휴대폰에서 눌러야 할 칩이 화면 밖·말풍선 밑에 숨던 것 → 보이는 곳으로 스크롤, 말풍선이 비켜 감

**게임 규칙 v30**
- 장중 속보가 나왔는데 그날 흐름이 반대인 날(속보의 약 7%), 속보 순간 가격이 반대로 크게 뛰어 '나쁜 속보에 급등'처럼 보이던 문제 → 속보 순간엔 속보 쪽으로 먼저 움직였다가 원래 흐름으로. 진행 중인 예전 판 가격은 그대로

**버그·화면 (오늘 오전 점검 포함)**
- 6명 판 순위 칸 잘림, 메뉴바가 긴 닉네임에 가려짐, 1위 동점 때 기권한 사람에게도 '무승부', 전적 동점 순위·이름 잘림
- 휴대폰 주문 창 금액 줄이 버튼에 가려짐, 예약 팔기 걸린 주식을 팔 때 안내
- 봇 방 '한 판 더'에 봇이 다시 앉음, 대기실 혼자일 때 봇으로 시작할 수 있다고 안내
- 고르기 칸 작은 글이 휴대폰에서 숨던 것, 빠른 참가 글자 꺾임, 가운데 알림이 반쪽 폭에 갇힘
- 금액 띄어쓰기('99만9,814원'), 뉴스 머리말 '[단독] [단독]', 여러 날 차트 시간 눈금에 날짜
- 첫 화면 파일 줄이기(약관 본문은 열 때만)

- 튜토리얼 뒤 '화면 멈춤' 조사: 시험 명령의 시간 제한이 브라우저를 끈 것으로 확인(게임 버그 아님)
- 감별 소식 고르기 창 머리말 두 번
- PC: '내 증강' 서랍에서 소식 진위 보기를 누르면 고르기 창이 서랍 밑에 깔려 못 누르던 것, PC 튜토리얼이 '내 증강' 줄을 비춤
- 튜토리얼 감별 결과: 커뮤니티 글을 골랐으면 '커뮤니티' 칸을 비추고 깜빡임

## 3. 확인한 것
- 단위 테스트 504개, 빌드, 실제 서버 자동 시험(전체), 기기 흉내 19종, 접근성 자동 점검, 운영 주소 시험
- 봇 균형 시뮬: 쉬움은 초보도 거의 이김(87~90%), 보통 29%, 어려움 22% — 목표대로

- 느린 휴대폰(4G 흉내·CPU 4배 느림) 첫 화면: 로딩 화면 0.26초, 로비·환영 창 약 2.3~2.7초(글자는 시스템 글꼴로 먼저 보이고, 한글 웹 글꼴로 바뀌는 때가 약 3.8~4.4초). 처음 온 기기는 세션 확인을 기다리지 않게, 게임 코드 미리 받기는 한가할 때로 바꿈. 남은 큰 몫은 CSS(압축 89KB)·글꼴 — 화면 전체를 다시 확인해야 해서 출시 뒤 과제로

- DB 크기 30MB(무료 500MB, 가장 큰 표 players 2.7MB) — 끝난 방 정리(되돌릴 수 없는 삭제)는 지금 얻는 게 작아 출시 뒤 이용자가 늘면
