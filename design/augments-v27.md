# 증강 (규칙 v27) — 찬스 카드를 없애고 롤토체스식 증강으로

증강 목록(90개)은 `design/augments-v27-list.md`. 이 문서는 **규칙**.

## 1. 한 줄 요약
카드(상점·무료 카드·방해·방어)를 모두 없앤다. 대신 정해진 날 아침에 **판 끝까지 이어지는 효과 3개 중 1개**를 고른다. 같은 방 모두 같은 등급(실버·골드·프리즘)에서 고르고, 효과는 서버가 계산한다.

## 2. 고르는 날 (롤토체스 2-1·3-2·4-2 ≈ 판의 20%·45%·65% 를 옮김)
| 판 길이 | 고르는 날 | 횟수 |
|---|---|---|
| 5일 | 1 · 3일차 | 2 |
| 6~12일 (10일) | 1 · 4 · 7일차 | 3 |
| 13일 이상 (20일) | 1 · 6 · 11 · 15일차 | 4 |
- 그날 **장 전 시간이 열릴 때** 고르기 창이 뜸. 장 전 시간이 없는 판(연습 무제한 등)은 장이 열릴 때.
- 고를 수 있는 시간: 그날 장이 끝나기 전까지. 안 고르면 장 마감 때 서버가 3개 중 하나를 무작위로 정함(롤토체스와 같음). 판은 멈추지 않음.

## 3. 등급 — 방 모두 같은 등급, 판 시작 때 한 번에 정함
롤토체스처럼 '등급 묶음'을 판 시작 때 서버 비밀값으로 한 번 뽑아 방 전체가 같이 씀. 증강 3개는 사람마다 다름.

| 3번 고르는 판 (10일) | 확률 |
|---|---|
| 골드-골드-골드 | 22% |
| 골드-실버-골드 | 16% |
| 실버-골드-골드 | 12% |
| 골드-골드-프리즘 | 12% |
| 골드-프리즘-골드 | 9% |
| 실버-골드-프리즘 | 8% |
| 실버-실버-골드 | 7% |
| 골드-실버-프리즘 | 6% |
| 프리즘-골드-골드 | 4% |
| 실버-프리즘-골드 | 3% |
| 프리즘-프리즘-프리즘 | 1% |
- 2번 판은 위 묶음의 앞 두 개, 4번 판은 마지막에 골드 60%·프리즘 40% 하나를 더함.
- **고르는 날 아침에 그 등급을 모두에게 공개**(방 공통이라 정보가 새지 않음). 다음 등급은 미리 알려 주지 않음.
- 내 다음 등급만 바꾸는 증강 2개: '외상 투자'(지금 +4만원, 다음 증강 한 등급 낮게) · '투자의 안목'(다음 증강 한 등급 높게). 실버보다 낮아지거나 프리즘보다 높아지지 않음.

## 4. 뜨는 규칙 (어떤 증강이 언제 뜰 수 있고 못 뜨는지)
증강마다 **등급 · 집안(I·II·III) · 종류 · 뜨는 때 · 조건 · 함께 못 가지는 것**을 적어 두고 서버가 아래 순서로 거름.
1. **그 등급만**: 방 공통 등급의 증강만.
2. **뜨는 때**: 증강마다 '초반(첫 번째)·중반·후반' 중 뜰 수 있는 때가 정해짐.
   - 돈 굴리기(이자·적금·월급·복리)·정보 '매일' 계열은 **초반·중반만** — 늦게 받으면 값어치가 없어서.
   - ⏳ 표시(며칠 뒤·며칠 들고 있기)는 **남은 날이 그 기간보다 짧으면 안 뜸**.
   - 따라잡기(꼴찌·대역전)는 **중반·후반만** — 첫날엔 순위가 없어서.
3. **조건(🎯)**: 업종 증강은 중반·후반에 **그 업종 종목을 지금 들고 있을 때만** 뜸(초반엔 아무나). 👥 표시는 여럿이 하는 판에서만, 혼자 판(연습·봇전 제외 규칙 따로)엔 안 뜸.
4. **집안 하나만**: 같은 집안(예: 짠테크 I·II·III) 중 하나를 가졌으면 그 집안은 다시 안 뜸. 이미 가진 증강도 안 뜸.
5. **함께 못 가지는 짝**: 예) '수수료 없는 세상' ↔ 다른 수수료 할인 · '현금왕' ↔ '레버리지 해금' · '단타 장인' ↔ '존버' 계열.
6. **3개가 모두 같은 종류면 안 됨**(돈·정보·거래·업종·버티기·따라잡기·재미). 롤토체스의 '경제 3개 금지'와 같음.
7. **판에 한 명만**: '잭팟'·'내부자 친구'는 한 방에서 한 사람만 가질 수 있음(이미 누가 골랐으면 그 방 다른 사람에게 안 뜸 — 누가 골랐는지는 안 알려 줌).
8. 후보가 3개보다 적으면 한 단계 아래 등급에서 채움(드문 경우).

## 5. 고르는 규칙
- 3개 중 1개. **다시 뽑기는 칸마다 1번**(마음에 드는 칸은 두고 그 칸만 새로, 등급 그대로) — 롤토체스 Set 9 이후 방식.
- 건너뛰기 없음(롤토체스와 같음). 대신 시간 안에 안 고르면 무작위.
- 고른 증강은 판 끝까지 유지, 바꿀 수 없음.
- **남에게 보이는지**: 롤토체스는 고른 증강이 보이지만, 우리는 상대 정보를 숨기는 원칙대로 **판이 끝날 때까지 안 보임**. 결과 화면에서 모두의 증강을 공개 — '누가 무엇으로 이겼나' 복기 재미.

## 6. 숫자 맞추기 (시뮬)
- 기준: 10일 판에서 기대 이득 실버 ≈ 재산의 +1~1.5% · 골드 ≈ +2.5~3.5% · 프리즘 ≈ +5~7%. 뉴스 잘 읽는 사람의 이득(지금 시뮬 +7~10%)보다 작게 — 증강보다 판단이 더 중요하게.
- 증강마다 `sim/augments.ts` 로 같은 봇에 증강 하나만 주고 100판씩 돌려 이득을 재서 표에 맞춤. 너무 센 것(레버리지 해금·타이밍의 신·복리)은 숫자를 낮추거나 뺌.

## 7. 서버가 정하는 것 / 화면에 보내는 것
| | 서버만 | 내 화면 | 상대 화면 |
|---|---|---|---|
| 등급 묶음 | 판 시작 때 `seeded(salt:augtier)` | 그날 등급(고르는 날부터) | 같은 등급(방 공통) |
| 보기 3개 | `seeded(salt:aug:자리:n번째:칸:다시뽑기)` + 4장 규칙으로 거름 | 내 보기·남은 다시 뽑기 | 없음 |
| 고른 증강 | 저장, 효과 계산 | 내 증강 목록·효과 숫자 | 없음(판 끝나면 결과에) |
| 효과(이자·보너스·환급) | 장 마감 때 계산해 '증강 수입' 줄로 저장 | 내 수입 내역 | 없음 |
| 정보 증강 | 지금 카드가 보여 주던 범위만(내일 헤드라인·강한 업종·고른 소식 진위·오를지 내릴지), `marketKey` 에 반영 | 그 정보 | 없음 |

절대 안 보냄: 상대 증강·보기, 다음 고르기 등급, salt·seed, 미래 가격·진실(카드가 보여 주던 범위 밖).

## 8. DB — `supabase/064_augments.sql` (여러 번 실행해도 안전)
- `augment_events(id, room_id, player_id, pick_n, kind in ('reroll','pick','auto'), slot, augment, day, created_at)`
  - 유니크: (player_id, pick_n) where kind in ('pick','auto') — 한 번만 고름
  - 유니크: (player_id, pick_n, slot) where kind='reroll' — 칸마다 한 번
- `augment_income(room_id, player_id, day, augment, amount)` — 이자·보너스·환급(서버가 장 마감 때 넣음, (player_id, day, augment) 유니크)
- 브라우저는 못 씀(RLS·권한 회수 — 지금 표들과 같음).
- v26 이하 방은 `items` 표·카드 규칙 그대로.

## 9. 진행 중인 판·없어지는 것
- v27 부터: 카드 사기·쓰기 거절, 무료 카드 없음, 방해·방어 없음. v26 이하 방은 끝날 때까지 카드 그대로.
- 가격·뉴스는 v26 과 같음(증강 난수는 전용 `aug27`) — 지문 테스트로 확인.
- **같이 바꿀 곳**: 봇(증강 고르기 — 쉬움은 무작위, 보통·어려움은 정보·돈 우선), 업적(카드 업적은 새 판에서 못 땀 → '첫 증강'·'프리즘 3번'·'증강 도감 절반' 같은 새 업적), 미션('카드 쓰기' → '증강 고르기'·'프리즘 증강 고르기'), 튜토리얼(1일차에 증강 고르기 한 번 — 연습봇 판은 '내부자 친구'가 꼭 나오게 해 뉴스 단서를 배우게), 통계(card_log → augment_log), 공부 탭·도감('증강 도감'), 운영자 현황(카드 표 → 증강 표).

## 10. 화면
- **고르는 날**: 화면 가운데 큰 창(휴대폰은 아래에서 올라오는 시트). 위에 '골드 증강을 골라요 · 4일차'. 증강 3개 — 그림·이름·등급 색 테두리(실버 회색·골드 금색·프리즘 무지갯빛은 테두리만)·효과 한 줄·조건 표시. 칸마다 작은 '다시 뽑기(1)'. 아래 남은 시간.
- 창을 닫아도 '오늘 증강을 아직 안 골랐어요' 띠가 남아 다시 열 수 있음.
- **내 증강**: 카드 칸 자리 → '내 증강' 칸. 고른 것과 오늘까지 받은 효과(예: '짠테크 II · 지금까지 +1.8만원').
- PC·휴대폰·태블릿·가로 모두 기기 시험으로 확인.

## 11. 악용 시나리오
| 시도 | 막는 법 |
|---|---|
| 보기에 없는 증강을 보냄 | 서버가 보기를 다시 계산해 확인 |
| 다시 뽑기를 여러 번 / 동시에 | 칸마다 DB 유니크 + 요청 번호 |
| 새로고침으로 보기 바꾸기 | 보기는 seed 로 정해져 같음 |
| 일부러 안 골라 뒤에 유리한 것 | 장 마감 때 서버가 자동으로 정하고 다음 날엔 못 고름 |
| 업종 조건을 잠깐 맞췄다 팔기 | 조건은 고르기 창이 처음 열린 순간(서버 기록)의 보유로 판단 |
| 정보 증강으로 미래 엿보기 | 카드가 보여 주던 범위만, 하루 횟수 제한, '새지 않음' 테스트 |
| '판에 한 명만' 증강으로 상대 증강 추리 | 안 뜨는 이유를 알려 주지 않음, 후보가 많아 추리가 어려움 |
| 보너스로 돈 무한 | 모든 보너스는 하루·판 상한, 장 마감 때 서버가 한 번만 계산(유니크) |
