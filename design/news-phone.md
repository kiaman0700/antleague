# 소식 칸 → '개미폰' (설계서, 2026-11-20)

## 1. 한 줄 요약
게임 안 '소식' 칸이 진짜 휴대폰처럼 바뀌어요. 홈 화면의 앱(뉴스·커뮤니티·SNS·메신저·방송)을 눌러 소식을 보고, 앱 아이콘에 안 읽은 수 배지가 붙고, 새 소식은 휴대폰 위쪽 알림으로 뜨고, 위에서 내리면 알림 모음이 보여요. 앱마다 알림을 켜고 끌 수 있어요.

## 2. 앱과 보여 주는 것 (지금 있는 소식을 앱별로 나눔 — 새 정보는 없음)
| 앱 | 바탕 | 모양 |
|---|---|---|
| 개미경제 (뉴스) | 아침 뉴스·장중 속보·시황 기사 | 언론사 앱: 기사 목록 → 누르면 기사 본문, 맨 위 '속보' 띠 |
| 개미광장 (커뮤니티) | 개미광장 글 | 게시판 목록: 제목·글쓴이·공감·댓글 |
| 종목토론방 (커뮤니티) | 종목토론방 글 | 종목별 게시판 모양 |
| 짹짹 (SNS) | 짹짹 글 | 짧은 글 타임라인, 일부 글에 그림 |
| 피드그램 (사진 SNS) | 피드그램 글 | 정사각 그림 + 글, 하트·댓글 |
| 개미톡 (메신저) | 개미톡 오픈채팅 글 + 장 전 소문 | 단톡방 말풍선 |
| 개미TV (방송) | 개미TV 라이브 글 | 방송 썸네일 그림 + 흐르는 채팅 |
| 설정 | — | 앱마다 알림 켜기·끄기, 알림 소리 |

- **그림:** 직접 그린 일러스트(공장·제품·차트 화면·회의실·현수막 등)를 글의 **업종·호재/악재·글 내용 해시**로 골라요. 외부 사진은 쓰지 않아요(저작권·보안 정책). 진짜/가짜와는 상관없이 골라서 그림으로 진위가 보이지 않게 해요.
- **배지:** 그 앱에서 오늘 안 읽은 소식 수(지금 있는 '읽음' 기록을 그대로 씀, 이 기기 저장).
- **알림:** 장중에 새 글·속보가 올라오면, 알림을 켠 앱만 휴대폰 위쪽에 2~3초 배너가 떠요. 위 상태 줄을 누르거나 끌어내리면 오늘 알림 모음(최신순, 누르면 그 글로). 기본값: 모두 켬, 개미TV만 끔 (바꾸려면 말씀해 주세요)
- **지금 있는 큰 '장중 속보' 알림은 그대로 둬요.** 게임에서 가장 중요한 순간이라서요 (기본값: 둠)

## 3. 서버 / 화면 데이터
- **서버·DB·규칙 변경 없음.** 화면이 이미 받고 있는 소식(공개된 뉴스·커뮤니티 글·장 전 소문)만 앱별로 나눠 보여 줘요.
- 새로 화면 데이터에 넣는 값: 없음
- 넣으면 안 되는 값(지금처럼): 글의 진위·들썩임·짚은 때, 아직 안 뜬 속보, 미래 가격 → 그대로 화면 데이터에 없음
- 알림 켜고 끄기·읽음은 이 기기에만 저장(localStorage) — 상대에게 아무것도 안 감

## 4. DB 변경: 없음
## 5. 진행 중인 게임: 영향 없음 (가격·소식·진위 그대로, 규칙 버전 그대로)

## 6. 화면
- **휴대폰 게임:** 아래 '소식' 탭 = 휴대폰 홈 화면(앱 격자 + 배지, 틀 없이 꽉 차게). 앱을 누르면 그 앱 화면, 왼쪽 위 '뒤로'·휴대폰 뒤로 가기로 홈. 위 상태 줄(게임 시각 '1일차 0:42')을 누르면 알림 모음.
- **PC 게임:** 오른쪽 소식 칸이 휴대폰 모양(둥근 틀·위 상태 줄), 같은 홈·앱. '크게 보기'는 큰 휴대폰.
- **태블릿:** 휴대폰과 같은 홈 화면.
- 관련 종목 칩·감별기 고르기·튜토리얼의 '뉴스에서 종목 찾기'는 그대로 동작(튜토리얼은 그 단계에서 뉴스 앱을 열어 둠).
- 움직임 줄이기 설정이면 배너·앱 열기 움직임 끔. 화면 읽기 프로그램용 이름표.

## 7. 악용 시나리오
- 그림·배지·알림 순서로 진위를 알아내기 → 그림은 진위와 무관한 값으로만 고르고, 알림은 공개된 글만, 순서는 올라온 시각 순(지금과 같음).
- 알림 끄기로 정보를 놓쳐 불리 → 앱 안에선 늘 다 보이고, 끄는 건 배너뿐.

## 8. 완료 기준

- [x] 앱 아이콘 배지 = 그 앱의 오늘 안 읽은 수, 앱을 열면 줄어든다
- [x] 장중 새 글이 오면 알림 켠 앱만 위쪽 배너가 뜨고, 끄면 안 뜬다 (설정이 새로 고침 뒤에도 남음)
- [x] 상태 줄을 누르거나 내리면 오늘 알림 모음이 보이고, 누르면 그 글이 열린다
- [x] 피드그램·짹짹·개미TV 글에 그림이 보이고, 같은 글은 늘 같은 그림 (테스트)

- 앱 줄임: 개미경제(뉴스) · **개미피드**(SNS 하나 — 게시판·짹짹·사진·단톡방·라이브 모양 글이 한 줄로 섞여 흐름, 위 칩으로 모양별 보기) · 개미증권(내 재산 칸 그대로) · 증강(또는 찬스 카드 칸 그대로) · 설정
- 홈 화면 위젯: 내 재산(재산·수익률·현금·큰 보유 3개, 누르면 개미증권) · 증강(고른 문양, 고를 차례면 호박색) · 오늘 안 읽은 소식 수(누르면 알림 모음)
- 개미 그림: 앱 아이콘(신문 속 개미·말풍선 개미·차트 위 개미·더듬이 보석), 글쓴이 사진(이름 해시로 고른 색의 개미 얼굴), 그림 속 사람 자리(개미 앵커·회의실 개미·안전모 개미·발표 개미·차트 보는 개미) — 진위와 무관(PostArt.test.ts 그대로 통과)
- 알림 설정: 개미경제·개미피드 + 피드 안 모양별(라이브는 기본 끔)
- PC: 오른쪽 칸 자체가 휴대폰(겉 '소식' 제목 없음), '크게 보기'는 뉴스 앱 위 줄
- 휴대폰: 아래 '개미폰'을 누르거나 아래 메뉴를 위로 쓸어 올리면 위 재산·장 마감 줄과 아래 메뉴 사이를 휴대폰이 채움. 맨 위 '내리기'(누르거나 아래로 쓸기)로 올리기 전 탭으로. 아래 홈 막대 = 홈 화면. 튜토리얼은 예전처럼 칸 안에
