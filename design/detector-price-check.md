# 루머 감별기 값 점검 (2026-11-18 새벽, 결정 필요)

## 알게 된 것
- v14부터 감별기는 소식 하나를 골라야(`pick`) 쓸 수 있는데, 봇(실제 봇·시뮬 봇)은 고르지 않고 써서 서버가 거절 → 봇의 무료 감별기가 헛돌았음. 고침: 봇은 오늘 소문 기사 → 장 전 찌라시 → 첫 뉴스 순으로 하나를 고름 (`src/engine/bots.ts`, `sim/bots.ts`). 봇 난이도 순서는 그대로.
- 시뮬(`sim/cards2.ts`, 3·11일차에 1장씩, 150판)에서 감별기 한 번이 주는 이득은 시작 돈의 약 1%.

| 감별기 값 | 1대1 쓴 사람 승률 | 4인 쓴 사람 승률 | 판당 금액 차이 |
|---|---|---|---|
| 10만 (지금) | 87% → 51% | 58% → 16% | −18% |
| 5만 | 85% → 68% | 57% → 31% | −9% |
| 3만 | 83% → 76% | 55% → 42% | −5% |

- 다른 카드는 값 1~3.5만에 판당 −0.3~−3%(거의 본전).

## 해석
- 시뮬 봇은 고른 소식 하나의 진위로 크게 벌지 못함(포지션이 작음). 사람이 발표 날 직전 큰 사건 찌라시에 쓰면 이득이 훨씬 클 수 있음 → 실제 판 기록(운영자 현황 '카드' 표, `npm run db -- stats` 카드 자세히)으로 확인 필요.
- 그래도 10만은 시뮬 기준 '사면 손해' 쪽이 뚜렷함.

## 고를 것 (사용자)
1. 10만 그대로 두고 실제 판 기록을 본 뒤 정하기
2. 3만으로 낮추기 (다음 규칙 버전 v16, 진행 중인 판은 그대로)
3. 5만 + 판정 범위를 '그 종목 관련 소식 전부'로 넓히기
