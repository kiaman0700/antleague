# 뉴스 강조 · 한 판 더(모드 표시) · 파티로 돌아가기

## 1. 한 줄 요약
- 뉴스가 이 게임의 핵심이니, 뉴스를 더 크게·먼저·눈에 띄게 보여 준다.
- 결과 화면의 "같은 설정으로 한 판 더"를 **무슨 모드인지 바로 보이는 버튼**으로 바꾼다.
- 파티로 한 판을 끝내면 **롤처럼 파티로 돌아가서** 파티장이 다시 찾기를 누르면 둘 다 같이 찾는다.

## 2. 뉴스 강조 (화면만 바뀜 — 규칙·서버 변화 없음)
| 어디 | 지금 | 바꾸는 것 |
|---|---|---|
| 휴대폰 아래 탭 | 종목·차트·뉴스·내 재산·카드 (뉴스가 3번째) | **뉴스를 맨 앞**으로: 뉴스·종목·차트·내 재산·카드. 게임 들어오면 뉴스 탭부터 (이미 대결은 뉴스부터 — 연습도 같게) |
| 휴대폰 뉴스 탭 아이콘 | 안 읽은 게 있으면 빨간 점 | 빨간 점 대신 **안 읽은 수 숫자** |
| 장중 속보 | 위쪽 알림 한 줄 (몇 초 뒤 사라짐) | 알림은 그대로 + **뉴스 목록 맨 위에 '속보' 띠**(빨간 왼쪽 선·'방금' 표시)를 그날 장이 끝날 때까지 고정 |
| 뉴스 카드 | 제목 15px, 종류 태그·관련 종목 칩 | 제목 **17px 굵게**, 호재(▲)/악재(▼)를 카드 왼쪽 굵은 색 띠로, 관련 종목 칩 조금 크게 |
| PC 뉴스 칸 | 오른쪽 좁은 칸(약 320px) | 넓은 화면(1440px 이상)에서 **380px**로 넓힘 + 칸 위에 **'크게 보기'** 버튼 → 가운데 차트 자리에 뉴스를 크게 (다시 누르면 차트) |

- 화면에 새로 보내는 값: **없음**. 가짜 여부·미래 뉴스·속보 시각은 지금처럼 숨김 (감별기 쓴 사람만 판정).
- 화면 편집(커스텀)에서 탭 순서를 바꿔 둔 사람은 그 순서를 그대로 둠 (기본값만 뉴스가 맨 앞).

## 3. 한 판 더 버튼 — 모드가 보이게
| 판 종류 | 지금 버튼 | 바뀐 버튼 (큰 글 / 작은 글) |
|---|---|---|
| 연습 | 같은 설정으로 한 판 더 | **연습 한 판 더** / 10일 · 하루 1분 |
| 일반전 혼자 | 같은 조건으로 다시 찾기 | **일반전 1대1 다시 찾기** / 신속 · 약 10~14분 |
| 랭킹전 | 같은 조건으로 다시 찾기 | **랭킹전 다인전 다시 찾기** / 일반 · 약 25~40분 |
| 커스텀·친구 방 | 같은 사람들과 한 판 더! | **이 사람들과 한 판 더** / 3명 · 10일 · 하루 1분 |
| 파티 | (파티원이 누르면 오류) | 아래 4번 |

- 버튼 아래 작은 글은 판 정보(인원·날수·하루 시간)로 자동으로 만듦.

## 4. 파티로 돌아가기 (롤 방식)
- 결과 화면: 파티로 한 판 했으면 버튼이 **"파티로 돌아가기"** 하나 (파티장·파티원 같음).
  - 누르면 일반전 화면(파티 칸이 있는 곳)으로 감. 파티는 그대로 유지돼 있음 (지금도 게임 끝나도 파티는 안 풀림).
- 파티 칸에 **파티원이 돌아왔는지** 표시: "돌아옴 ✓ / 아직 결과 보는 중".
  - 서버: 파티 정보(`party`)에 파티원별 `back`(진행 중 게임·대기실이 없고 1분 안에 접속) 한 칸만 추가. 닉네임 외 다른 정보 없음.
- **파티장**: 파티원이 모두 돌아오면 '일반전 찾기'가 켜짐 (돌아오기 전엔 "파티원을 기다리는 중"으로 꺼짐 — 지금은 누르면 오류).
- **파티원**: "파티장이 찾기를 시작하면 같이 찾아요" 안내. 파티장이 찾기 시작하면 지금처럼 자동으로 '찾는 중'.
- 파티원이 결과 화면에 계속 머물러 있는데 파티장이 찾기를 누르면: 결과 화면 위에 "파티장이 다시 찾고 있어요 · 파티로 가기" 알림.
  - 기본값: 알림만 (자동으로 끌고 가지 않음 — 결과를 보던 중일 수 있어서). 바꾸려면 말씀해 주세요.

## 5. 서버가 정하는 것 / 화면에 보내는 것
| 값 | 어디서 | 보내도 되나 |
|---|---|---|
| 판 종류·인원·날수·하루 시간 | 이미 화면 데이터에 있음 | 그대로 |
| 파티원 `back`(돌아왔는지) | 서버 `party` 응답에 추가 | 같은 파티원끼리만, 참/거짓만 |
| 파티장이 찾기 시작했는지 | 서버 `party` 응답(이미 대기표 상태 있음) | 같은 파티원끼리만 |

## 8. 악용 시나리오
- 남의 파티 상태 엿보기 → `party` 는 내가 속한 파티만 돌려줌 (지금과 같음).
- 파티원이 안 돌아온 채 파티장이 억지로 찾기 → 서버가 지금처럼 거절 (진행 중 게임·접속 확인).
